# 黄山旅游信息文档

## 城市概况

黄山，古称歙州、徽州，是安徽省辖地级市，位于安徽省最南端，皖浙赣三省交界处，素有"天下第一奇山""徽州文化发祥地"之美誉。全市总面积9807平方公里，常住人口约140万，下辖3个区4个县。黄山是一座有着2200多年建城史的国家历史文化名城，是徽州文化的核心发祥地，自古就有"五岳归来不看山，黄山归来不看岳"之美誉。

黄山最著名的旅游名片当属黄山风景区、宏村、西递、屯溪老街、唐模等。黄山风景区是中国十大名山之一，也是世界文化与自然双重遗产，以"奇松、怪石、云海、温泉"四绝著称，被誉为"天下第一奇山"。宏村和西递是徽州古村落的典型代表，也是世界文化遗产。黄山属亚热带季风气候，四季分明，最佳旅游时间为3-5月和9-11月，冬季雪景也别具特色。

## 旅游景点

### 1. 黄山风景区

- **地址**：黄山市黄山区汤口镇黄山风景区管理处
- **门票**：190元/人（旺季），150元/人（淡季）
- **简介**：黄山风景区位于黄山市境内，是中国十大名山之一，也是世界文化与自然双重遗产、国家AAAAA级旅游景区。黄山古称"黔山"，因传说黄帝在此炼丹升天而改名为"黄山"，素有"天下第一奇山""五岳归来不看山，黄山归来不看岳"之美誉。

黄山风景区占地面积约154平方公里，其中精华景区约54平方公里，以"奇松、怪石、云海、温泉"四绝著称于世。奇松中以迎客松最为著名，它破石而生，姿态优美，已成为黄山和中华民族热情好客的象征。怪石千姿百态，有名可称的怪石有1200余处，如"飞来石""松鼠跳天都""猴子观海"等，栩栩如生，令人叹为观止。云海是黄山最壮观的景观之一，每年11月至次年5月是观云海的最佳时节，白云在山谷中翻腾，波涛汹涌，气势磅礴。建议游览时间2-3天。

### 2. 宏村景区

- **地址**：黄山市黟县宏村镇宏村景区
- **门票**：104元/人（成人），52元/人（学生/老人）
- **简介**：宏村位于黄山市黟县东北部，是古黟桃花源里一座奇特的牛形古村落，也是世界文化遗产、国家AAAA级旅游景区。宏村始建于南宋绍兴元年（1131年），距今已有890多年历史，因"扩而成太乙象，故而美曰弘村"，清乾隆年间更名为宏村。

宏村最著名的景观是"牛形村落"布局和"南湖春晓""月沼风荷"等水景。整个村落鳞次栉比的古民居群，宛如一头斜卧山前溪边的青牛，村头的雷岗山为牛头，村口的两棵古树为牛角，错落有致的民居群为牛身，泗洪桥为牛尾，四附近的4座古桥为牛腿，设计精巧，构思独特，是徽州风水文化和建筑艺术的杰出代表。南湖位于宏村南端，湖面开阔，湖水清澈，湖畔杨柳依依，是宏村最著名的景观之一，也是《卧虎藏龙》等电影的取景地。建议游览时间半天至一天。

### 3. 西递景区

- **地址**：黄山市黟县西递镇西递村
- **门票**：104元/人（成人），52元/人（学生/老人）
- **简介**：西递位于黄山市黟县东部，是徽州古村落的典型代表，也是世界文化遗产、国家AAAA级旅游景区。西递始建于北宋庆历七年（1047年），距今已有970多年历史，因村边有水西流，又因古有递送邮件的驿站，故得名"西递"。

西递保存有完整的古村落格局和大量的明清建筑，现有明清古民居124幢、祠堂3幢，其中胡文光刺史牌坊是西递的标志性建筑，建于明万历六年（1578年），坊上有"恩荣"二字，是皇帝赐予胡文光的荣誉。西递的古民居建筑风格独特，粉墙黛瓦，马头墙翘角，天井院落，门窗槅扇雕刻精美，充分体现了徽派建筑的精髓。村内有大量的牌坊、祠堂、民居、古桥、古井等历史文化遗迹，是了解徽州文化、体验古村落慢生活的绝佳去处。建议游览时间半天至一天。

### 4. 屯溪老街

- **地址**：黄山市屯溪区老街（屯溪老街历史文化街区）
- **门票**：免费开放
- **简介**：屯溪老街位于黄山市中心城区，是一条保存完好的宋代商业长街，也是中国保存最完整、最具有南宋和明清建筑风格的古代街市，素有"活着的清明上河图""中国第一条历史文化街区"之美誉。

屯溪老街全长1273米，其中中心街长832米，两侧店铺林立，多为双层砖木结构，清一色的徽派建筑风格，粉墙黛瓦，马头墙翘角，古色古香。老街上汇聚了黄山毛峰、徽墨、歙砚、徽州漆器、徽派版画等各类徽州特产和手工艺品店，是购买黄山特产和纪念品的最佳去处。老街上的同德仁药店、程德馨酱园、胡开文墨厂等老字号，已有数百年历史，是黄山商业文化的重要见证。夜晚的屯溪老街格外迷人，红灯笼高高挂起，古街在灯光的映照下更显古色古香，是体验徽州文化、品尝黄山美食的绝佳去处。建议游览时间2-3小时。

### 5. 唐模景区

- **地址**：黄山市徽州区潜口镇唐模村
- **门票**：80元/人（成人），40元/人（学生/老人）
- **简介**：唐模位于黄山市徽州区，是徽州古村落之一，也是国家AAAA级旅游景区。唐模始建于唐代，距今已有1100多年历史，因大唐模范村而得名"唐模"，又因村中有一条小溪穿村而过，形似一条龙，故又名"龙川"。

唐模最著名的景观是"水街"和"水口"园林。水街是唐模村的精华所在，溪水穿村而过，两岸民居错落有致，溪上建有13座形态各异的古石桥，溪流、古桥、民居、古树相映成趣，美不胜收，被誉为"中国水口园林第一村"。水口园林位于村头，是徽州村落水口文化的典型代表，园内古树参天，溪水潺潺，亭台楼阁点缀其间，是徽州园林艺术的杰出代表。唐模还是著名导演陈凯歌电影《徽州女人》的取景地之一，是了解徽州水口文化、体验古村落慢生活的绝佳去处。建议游览时间2-3小时。

## 美食餐厅

### 1. 徽商故里（屯溪老街店）

- **地址**：黄山市屯溪区老街248号
- **推荐菜品**：臭鳜鱼、毛豆腐、徽州刀板香
- **人均消费**：80-150元
- **简介**：徽商故里是黄山最著名的徽菜餐厅，以正宗徽州菜为主，臭鳜鱼是徽菜的代表作，闻起来臭，吃起来香，肉质鲜嫩，是到黄山必尝的特色美食。

### 2. 老街第一楼（屯溪老街店）

- **地址**：黄山市屯溪区老街168号
- **推荐菜品**：徽州毛豆腐、胡适一品锅、问政山笋
- **人均消费**：60-120元
- **简介**：老街第一楼位于屯溪老街内，是黄山最有名的徽菜餐厅之一，以徽州传统菜肴为主，毛豆腐是必尝的特色小吃，外焦里嫩，鲜香味美。

### 3. 黄山特色小吃（屯溪老街聚集区）

- **地址**：黄山市屯溪区老街（多家小吃店）
- **推荐菜品**：毛豆腐、石头粿、蟹壳黄烧饼
- **人均消费**：20-50元
- **简介**：屯溪老街是黄山最著名的小吃聚集区，汇聚了黄山各种特色小吃和徽州美食，是品尝黄山特色小吃、体验徽州饮食文化的绝佳去处。

### 4. 徽州府衙（歙县徽州古城内）

- **地址**：黄山市歙县徽州古城内
- **推荐菜品**：徽州一品锅、腊月腊肉、问政山笋
- **人均消费**：100-180元
- **简介**：徽州府衙是歙县最有名的徽菜餐厅，以徽州传统宴席菜为主，做工精细，口味醇厚，是体验徽州官府菜、了解徽州饮食文化的绝佳去处。

### 5. 黟县宏村农家乐（宏村内多家）

- **地址**：黄山市黟县宏村内（多家农家乐）
- **推荐菜品**：腊八豆腐、笋衣烧肉、徽州刀板香
- **人均消费**：50-100元
- **简介**：宏村内有大量的农家乐餐厅，以徽州家常菜和农家菜为主，食材新鲜，口味地道，是体验徽州乡村美食、感受古村落慢生活的绝佳去处。

- **价格区间**：300-1500元/晚
- **特色**：位于黄山风景区内，方便游客观赏日出、云海等景观，是游览黄山期间理想的住宿选择，但需提前预订。

## 交通信息

- **机场**：黄山屯溪国际机场，位于黄山市屯溪区，距市中心约5公里，已开通多条国内航线。
- **火车站**：黄山北站（高铁站，位于屯溪区），黄山站（位于屯溪区）。
- **汽车**：黄山汽车客运总站位于屯溪区，有发往各个景区的旅游班车，交通十分便利。
- **公交**：黄山市区公交线路发达，票价1-2元，部分旅游专线可直达黄山风景区、宏村、西递等主要景点。
- **出租车/网约车**：起步价7元（2.5公里），超过2.5公里后每公里2.5元。

## 旅游小贴士

1. **最佳旅游时间**：春季（3-5月）和秋季（9-11月）气候宜人，是游览黄山的最佳时节；冬季（12-2月）雪景也别具特色。
2. **游览建议**：建议安排3-5天时间游览黄山，可将黄山风景区、宏村、西递、屯溪老街等景点串联游览。
3. **特色体验**：登山观赏奇松、怪石、云海、温泉四绝；参观徽州古村落了解徽州文化；品尝地道的徽州美食（臭鳜鱼、毛豆腐等）。
4. **购物推荐**：屯溪老街是黄山最繁华的旅游商业街，可以购买到各类黄山特产（黄山毛峰、徽墨、歙砚等）和纪念品。
5. **注意事项**：黄山风景区海拔较高，上下山需注意安全，建议穿着舒适防滑的登山鞋；山上气候变化快，需备好雨具和保暖衣物；品尝臭鳜鱼等特色美食时，注意选择正规餐厅。
