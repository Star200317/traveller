# 舟山旅游信息文档

## 城市概况

舟山，别称翁山、昌国，是浙江省辖地级市，位于浙江省东北部，舟山群岛之上，是中国第一个以群岛建市的地级市，素有"东海鱼仓""海鲜之都"之美誉。全市总面积2.22万平方公里（其中海域面积2.08万平方公里），常住人口约115万，下辖2个区2个县。舟山是一座有着1000多年建城史的国家历史文化名城，是中华文明的重要发祥地之一，自古就有"东海瀛洲""海鲜之都"之美誉。

舟山最著名的旅游名片当属普陀山、嵊泗列岛、桃花岛、东极岛、朱家尖等。普陀山是中国佛教四大名山之一，也是观音菩萨的根本道场，素有"海天佛国""南海圣境"之美誉。嵊泗列岛是国家级风景名胜区，以碧海蓝天、金沙奇石著称，被誉为"东海蓬莱"。舟山属亚热带季风气候，四季分明，气候温和，雨量充沛，最佳旅游时间为5-10月。

## 旅游景点

### 1. 普陀山风景名胜区

- **地址**：舟山市普陀区普陀山岛
- **门票**：160元/人（旺季），140元/人（淡季）
- **简介**：普陀山位于舟山市普陀区，是舟山群岛中的一个小岛，与山西五台山、四川峨眉山、安徽九华山并称为中国佛教四大名山，也是观音菩萨的根本道场，素有"海天佛国""南海圣境"之美誉，国家AAAAA级旅游景区。普陀山占地面积约12.5平方公里，素有"第一人间清净地"之美誉。

普陀山佛教文化历史悠久，早在后梁时期（916年），日本僧人慧锷从五台山迎奉观音像回国，途经普陀山被大风所阻，便在普陀山建"不肯去观音院"，从此开创了普陀山佛教文化的先河。普陀山主要景点包括普济寺、法雨寺、慧济寺三大寺，以及南海观音大佛像、紫竹林、百步沙、千步沙等自然景观。其中南海观音大佛像高33米，是普陀山的标志性建筑，佛像庄严雄伟，面朝大海，慈眉善目，是普陀山最著名的景观之一。建议游览时间1-2天。

### 2. 嵊泗列岛风景名胜区

- **地址**：舟山市嵊泗县嵊泗列岛
- **门票**：免费开放（部分景点收费，如基湖沙滩40元/人）
- **简介**：嵊泗列岛位于舟山市北部，是国家级风景名胜区，由404个岛屿组成，其中有人居住的岛屿16个，素有"东海蓬莱""碧海奇礁，金沙渔火"之美誉。嵊泗列岛海域面积8747平方公里，其中陆域面积86平方公里，是舟山最具代表性的海岛旅游度假区。

嵊泗列岛最著名的景观包括基湖沙滩、南长涂沙滩、六井潭、大悲山、花鸟灯塔、嵊山岛"绿野仙踪"等。基湖沙滩是华东地区最大的沙滩之一，全长2200米，宽200多米，沙质细腻柔软，是理想的海滨浴场。花鸟灯塔建于清同治九年（1870年），是舟山群岛最古老的灯塔之一，也是远东第一大灯塔，至今仍在使用中，是嵊泗列岛的标志性建筑之一。建议游览时间1-2天。

### 3. 桃花岛风景名胜区

- **地址**：舟山市普陀区桃花岛
- **门票**：免费开放（部分景点收费，如桃花寨30元/人）
- **简介**：桃花岛位于舟山市普陀区，是舟山群岛中的第七大岛，因金庸先生的武侠小说《射雕英雄传》和《神雕侠侣》而闻名遐迩，素有"海山仙子国""东方琅環"之美誉。桃花岛占地面积约40.37平方公里，是舟山最具武侠文化特色的旅游岛屿。

桃花岛因岛上遍植桃花而得名，每年3-4月桃花盛开，漫山遍野，如诗如画，是桃花岛最著名的景观之一。岛上主要景点包括桃花寨、安期峰、大佛岩、桃花港、鹁鸪门、乌石砾滩等，其中桃花寨是金庸武侠文化主题景区，建有黄药师山庄、冯氏墓、靖哥居等武侠主题景观，是金庸迷的必游之地。安期峰是桃花岛的最高峰，海拔539.7米，登顶可俯瞰全岛美景和周围海域，是桃花岛最佳的观景位置。建议游览时间1天。

### 4. 东极岛

- **地址**：舟山市普陀区东极镇
- **门票**：免费开放
- **简介**：东极岛位于舟山市普陀区东极镇，是中国最东面的住人岛屿，由庙子湖岛、青浜岛、东福山岛、黄兴岛等28个岛屿组成，素有"东极之东""东海极地"之美誉。东极岛因2013年韩寒导演的电影《后会无期》在此取景而名声大噪，成为了年轻人向往的"远方"和"诗"的代名词。

东极岛最著名的景观包括庙子湖岛的网红灯塔、新世纪第一道曙光照射点、东福山岛的象鼻峰、大树湾石屋群、青浜岛的"海上布达拉宫"等。东福山岛是大陆最东面的住人岛屿，每天中国在这里迎来第一缕阳光，是观日出的绝佳位置。大树湾石屋群是东极岛最具特色的民居建筑，全部用石块砌成，层层叠叠，错落有致，被誉为"海上布达拉宫"。东极岛不仅是观光胜地，也是体验渔家文化、品尝新鲜海鲜的绝佳去处。建议游览时间1-2天。

### 5. 朱家尖

- **地址**：舟山市普陀区朱家尖岛
- **门票**：免费开放（南沙景点旺季70元/人）
- **简介**：朱家尖位于舟山市普陀区，与普陀山隔海相望，是舟山群岛中的第五大岛，素有"沙雕故乡""东方夏威夷"之美誉。朱家尖占地面积约72平方公里，以沙雕艺术、海滨浴场、佛教文化而著称，是舟山最具活力的旅游岛屿之一。

朱家尖最著名的景观包括南沙、东沙、白山、大青山、观音法界等。南沙是朱家尖最具代表性的海滨浴场，全长1000余米，沙质细腻，海水清澈，每年9月在此举行国际沙雕节，吸引了大量游客和沙雕艺术家前来参观。大青山国家森林公园是朱家尖的最高点，海拔378.6米，公园内建有全长30公里的环岛旅游大道，沿途风光旖旎，是自驾游的绝佳选择。观音法界是位于朱家尖的佛教文化主题景区，建筑宏伟，金碧辉煌，是舟山市新的佛教文化地标。建议游览时间1-2天。

## 美食餐厅

### 1. 沈家门海鲜夜排档（总店）

- **地址**：舟山市普陀区沈家门滨港路198号
- **推荐菜品**：梭子蟹、带鱼、大黄鱼、嵊泗螺酱
- **人均消费**：150-250元
- **简介**：沈家门海鲜夜排档是舟山最有名的海鲜聚集地，已有30多年历史，沿沈家门渔港而建，灯火辉煌，是品尝舟山海鲜的绝佳去处。

### 2. 舟山海鲜面（各早餐店均有）

- **地址**：舟山市定海区、普陀区各早餐店
- **推荐菜品**：海鲜面、梭子蟹面、带鱼面、黄鱼面
- **人均消费**：20-40元
- **简介**：海鲜面是舟山最具代表性的特色小吃，用当天捕捞的新鲜海鲜和手擀面烹制而成，汤头鲜美，面条筋道，是舟山人最喜爱的早餐之一。

### 3. 嵊泗海鲜（菜园镇海鲜街）

- **地址**：舟山市嵊泗县菜园镇海滨路（多家海鲜餐厅）
- **推荐菜品**：嵊泗螺酱、海带排骨汤、清蒸梭子蟹、葱油海瓜子
- **人均消费**：100-200元
- **简介**：嵊泗海鲜以新鲜、原汁原味著称，烹饪方式以清蒸、白灼、葱油为主，保留了海鲜的原本鲜味，是体验舟山海鲜文化的绝佳去处。

### 4. 东极岛海鲜（庙子湖岛海鲜街）

- **地址**：舟山市普陀区东极镇庙子湖岛（多家海鲜餐厅）
- **推荐菜品**：清蒸石斑鱼、酱爆海螺、海鲜炒年糕、鱼丸汤
- **人均消费**：80-150元
- **简介**：东极岛海鲜以野生小海鲜为主，肉质鲜嫩，味道鲜美，价格相对实惠，是体验东极岛渔家文化、品尝地道海鲜的绝佳去处。

### 5. 朱家尖海鲜（南沙海鲜大排档）

- **地址**：舟山市普陀区朱家尖岛南沙景区周边（多家大排档）
- **推荐菜品**：烤鱿鱼、海鲜炒饭、海鲜烧烤、冰镇海螺
- **人均消费**：60-120元
- **简介**：朱家尖海鲜大排档是舟山最具特色的海鲜夜宵聚集地，傍晚时分开始营业，海鲜新鲜，价格实惠，是体验朱家尖夜生活的绝佳去处。

## 住宿推荐

### 1. 舟山喜来登绿城酒店

- **地址**：舟山市定海区千岛路188号
- **价格区间**：800-1800元/晚
- **特色**：五星级豪华酒店，位于定海城区，紧邻千岛海景，装修典雅豪华，设施一流，服务优质，是商务出行和高端旅游的理想选择。

### 2. 普陀山雷迪森庄园

- **地址**：舟山市普陀区普陀山岛法雨路28号
- **价格区间**：600-1500元/晚
- **特色**：精品禅意酒店，位于普陀山岛上，环境清幽，充满佛教文化气息，是体验普陀山佛教文化、修身养性的理想住宿选择。

### 3. 如家酒店（舟山沈家门店）

- **地址**：舟山市普陀区沈家门滨港路128号
- **价格区间**：200-400元/晚
- **特色**：经济型连锁酒店，位于沈家门渔港附近，交通便利，房间干净整洁，性价比高，适合预算有限的游客。

### 4. 嵊泗民宿聚集区（菜园镇、基湖村）

- **地址**：舟山市嵊泗县菜园镇、基湖村（多家民宿）
- **价格区间**：150-500元/晚
- **特色**：海岛特色民宿，位于嵊泗列岛内，部分民宿紧邻海滩，可以体验渔家生活、品尝新鲜海鲜，是体验海岛慢生活的理想住宿选择。

### 5. 东极岛渔家民宿（庙子湖岛、东福山岛）

- **地址**：舟山市普陀区东极镇庙子湖岛、东福山岛（多家渔家民宿）
- **价格区间**：100-300元/晚
- **特色**：渔家特色民宿，位于东极岛各岛上，主人热情好客，提供家常海鲜餐食，可以体验渔家生活、观看东海日出，是体验东极岛慢生活的经济之选。

## 交通信息

- **机场**：舟山普陀山国际机场，位于舟山市普陀区朱家尖岛，距舟山本岛约20公里，已开通多条国内航线。
- **海上客运**：舟山本岛（定海、沈家门）有发往普陀山、嵊泗、东极岛、桃花岛等岛屿的客轮，是游览舟山群岛的主要交通方式。
- **公交**：舟山本岛公交线路发达，票价2-5元，部分旅游专线可直达主要景点。
- **出租车/网约车**：起步价10元（3公里），超过3公里后每公里2.5元。

## 旅游小贴士

1. **最佳旅游时间**：夏季（5-10月）气候凉爽，是游览舟山的最佳时节；7-9月是下海游泳的黄金季节。
2. **游览建议**：建议安排3-5天时间游览舟山，可将普陀山、嵊泗列岛、桃花岛、东极岛、朱家尖等景点串联游览。
3. **特色体验**：品尝地道的舟山海鲜，参观普陀山感受佛教文化，体验东极岛的"远方"和"诗"。
4. **购物推荐**：沈家门渔港、普陀山香华街是舟山最繁华的购物区，可以购买到各类海鲜干货和舟山特产。
5. **注意事项**：舟山是群岛，各岛之间交通靠船只，需提前了解船期表；台风季节（7-9月）需注意天气变化，以免被困岛上；品尝海鲜时注意选择正规餐厅，避免被宰。
