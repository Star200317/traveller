# 扬州旅游信息文档

## 城市概况

扬州，古称广陵、江都、维扬，是江苏省辖地级市，位于江苏省中部，长江下游北岸，江淮平原南端，素有“淮左名都”“竹西佳处”之美誉。全市总面积6591.21平方公里，常住人口约460万，下辖3个区2个县1个县级市。扬州是一座有着2500多年建城史的世界美食之都，是中华文明的重要发祥地之一，自古就有“烟花三月下扬州”之美誉。

扬州最著名的旅游名片当属瘦西湖、个园、何园、大明寺、东关街等。瘦西湖是扬州最具标志性的景观，也是世界文化遗产大运河的重要组成部分，湖光水色美不胜收，被誉为“两岸花柳全依水，一路楼台直到山”。个园是中国四大名园之一，以竹石取胜，被誉为“春夏秋冬四季假山”。扬州属亚热带季风气候，四季分明，气候温和，雨量充沛，最佳旅游时间为3-5月和9-11月。

## 旅游景点

### 1. 瘦西湖景区

- **地址**：扬州市邗江区大虹桥路28号
- **门票**：100元/人（旺季），60元/人（淡季）
- **简介**：瘦西湖位于扬州市西北部，是扬州最具标志性的景观，也是世界文化遗产大运河的重要组成部分，国家AAAAA级旅游景区。瘦西湖原名“保障湖”，因湖面瘦长、蜿蜒曲折而得名“瘦西湖”，湖身全长约4.3公里，游览面积达168.32公顷。

瘦西湖以“瘦”为特色，湖身狭长，蜿蜒曲折，两岸花柳依水，楼台亭阁掩映其间，移步换景，美不胜收。景区内主要景点包括大虹桥、小金山、五亭桥、白塔、二十四桥、万花园、徐园、四桥烟雨等，其中五亭桥是瘦西湖的标志性建筑，建于清乾隆二十二年（1757年），桥上建有五座亭子，造型独特，黄瓦朱柱，浮现在湖面上，被誉为“中国最秀美的桥”。二十四桥因唐代诗人杜牧的诗句“二十四桥明月夜，玉人何处教吹箫”而闻名遐迩。建议游览时间半天至一天。

### 2. 个园

- **地址**：扬州市广陵区盐阜东路10号
- **门票**：45元/人（旺季），30元/人（淡季）
- **简介**：个园位于扬州市广陵区，是清代嘉庆二十三年（1818年）盐商黄至筠在明代“寿芝园”旧址上扩建而成的私宅园林，也是中国四大名园之一，国家AAAA级旅游景区。个园占地面积约2.3公顷，以竹石取胜，园内遍植各类竹子，因竹叶形似“个”字而得名“个园”。

个园最著名的景观是“春夏秋冬四季假山”，这是中国古典园林中独一无二的景观设计。春山选用竹笋石，象征春回大地、万物复苏；夏山选用太湖石，灰调素雅，象征夏日清凉；秋山选用黄石，赭石色调，象征秋日丰收；冬山选用宣石（雪石），白石如雪，象征冬日雪景。四季假山构思精巧，工艺精湛，充分体现了中国古典园林“咫尺山林，多方胜景”的造园理念。建议游览时间2-3小时。

### 3. 何园（寄啸山庄）

- **地址**：扬州市广陵区徐凝门大街66号
- **门票**：45元/人（旺季），30元/人（淡季）
- **简介**：何园位于扬州市广陵区，始建于清光绪九年（1883年），是清代晚期建造的大型私家园林，也是国家AAAA级旅游景区。何园原名“寄啸山庄”，因园主何芷舠曾任湖北汉黄德道台，辞官归里后建此园，取陶渊明“倚南窗以寄傲，审容膝之易安”和“登东皋以舒啸，临清流而赋诗”之意，命名为“寄啸山庄”，简称“何园”。

何园占地面积约1.4公顷，建筑风格中西合璧，既有中国传统园林的山水布局，又有西方建筑的元素，是扬州园林中中西合璧的代表作。园内有“天下第一廊”（复道回廊）、“天下第一山”（片石山房）、“天下第一窗”（水心亭窗景）、“天下第一亭”（水心亭）等“四个一”景观，其中复道回廊全长约1500米，被誉为“中国立交桥的雏形”。片石山房是何园内最著名的景观，相传为石涛和尚的手笔，假山叠石精巧绝伦，被誉为“石涛叠石的人间孤本”。建议游览时间2-3小时。

### 4. 大明寺（鉴真纪念堂）

- **地址**：扬州市邗江区平山堂东路8号（瘦西湖西侧）
- **门票**：45元/人（旺季），30元/人（淡季）
- **简介**：大明寺位于扬州市西北郊，蜀岗中峰之上，始建于南朝宋孝武帝大明年间（457-464年），距今已有1500多年历史，是扬州最古老的寺庙之一，也是唐代高僧鉴真大师的出家地和弘法道场。大明寺因始建于大明年间而得名，清乾隆三十年（1765年）乾隆皇帝巡视扬州时，因忌讳“大明”二字，曾下令改名为“栖灵寺”，但民间仍习称“大明寺”。

大明寺占地面积约500亩，主要建筑包括天王殿、大雄宝殿、鉴真纪念堂、平山堂、谷林堂、欧阳修祠、西园等，其中鉴真纪念堂是为纪念鉴真大师而建，由建筑大师梁思成先生主持设计，建筑风格仿照日本奈良唐招提寺金堂，庄严雄伟，是中日文化交流的重要见证。平山堂是北宋文坛领袖欧阳修任扬州太守时所建，堂前平台视野开阔，江南诸山拱揖槛前，若可攀跻，故名“平山堂”，是扬州文化的重要象征。建议游览时间2-3小时。

### 5. 东关街历史街区

- **地址**：扬州市广陵区东关街（东至古运河，西至国庆路）
- **门票**：免费开放
- **简介**：东关街位于扬州市广陵区，是扬州最具代表性的历史文化街区，也是中国历史文化名街。东关街全长1122米，宽约5米，街面由长条石铺成，两侧商铺林立，保留了大量的明清建筑和民国建筑，是扬州古城风貌保存最完好的历史街区之一。

东关街始建于唐代，兴盛于明清，是古代扬州水陆交通的要冲，也是商业、手工业和宗教文化的中心。街区内保存有完善的街巷格局和传统建筑风貌，主要景点包括个园（位于街区北端）、逸圃、汪氏小苑、扬州剪纸博物馆、武当行宫、准提寺等，还有各式各样的扬州特色小吃和手工艺品店，是体验扬州古城文化、品尝扬州美食的绝佳去处。东关街的夜景格外迷人，古街灯火辉煌，游人如织，展现了“夜扬州”的独特魅力。建议傍晚时分前往，可以同时欣赏日景和夜景，游览时间2-3小时。

## 美食餐厅

### 1. 富春茶社（国庆路总店）

- **地址**：扬州市广陵区国庆路125号
- **推荐菜品**：蟹黄汤包、大煮干丝、翡翠烧卖
- **人均消费**：80-120元
- **简介**：富春茶社始创于清光绪十一年（1885年），是扬州最著名的百年老字号，也是淮扬菜的代表性餐厅。以淮扬细点和淮扬菜肴为主，蟹黄汤包汤汁鲜美，大煮干丝做工精细，是体验正宗淮扬美食的绝佳去处。

### 2. 冶春茶社（御码头店）

- **地址**：扬州市邗江区大虹桥路22号（御码头旁）
- **推荐菜品**：蟹黄汤包、五丁包子、千层油糕
- **人均消费**：70-110元
- **简介**：冶春茶社始创于清乾隆年间，是扬州最著名的茶社之一，以淮扬细点和早茶闻名。餐厅位于瘦西湖畔，环境优雅，是体验扬州“早上皮包水”文化的最佳去处。

### 3. 扬州炒饭（老扬州炒饭店）

- **地址**：扬州市广陵区东关街128号
- **推荐菜品**：扬州炒饭、大煮干丝、文思豆腐
- **人均消费**：30-60元
- **简介**：扬州炒饭是扬州最具代表性的特色美食，相传起源于隋朝越国公杨素创制的“碎金饭”，相传隋炀帝巡游扬州时将“碎金饭”传入扬州，后经不断改进，成为了扬州最具代表性的美食名片。

### 4. 三头宴（扬州大酒店）

- **地址**：扬州市广陵区汶河北路50号
- **推荐菜品**：扒烧整猪头、蟹粉狮子头、拆烩鲢鱼头
- **人均消费**：100-180元
- **简介**：三头宴是淮扬菜的代表性宴席，以扒烧整猪头、蟹粉狮子头、拆烩鲢鱼头三道大菜为主，做工精细，口味鲜美，是体验淮扬菜精髓的绝佳去处。

### 5. 扬州小吃聚集区（东关街、彩衣街）

- **地址**：扬州市广陵区东关街、彩衣街（多家小吃店）
- **推荐菜品**：扬州包子、大煮干丝、三丁包子、千层油糕、翡翠烧卖
- **人均消费**：40-80元
- **简介**：东关街和彩衣街是扬州最著名的小吃聚集区，汇聚了扬州各种特色小吃和老字号餐厅，是品尝扬州美食、体验扬州古城文化的绝佳去处。

## 住宿推荐

### 1. 扬州迎宾馆

- **地址**：扬州市邗江区长春路1号（瘦西湖畔）
- **价格区间**：800-1800元/晚
- **特色**：国宾馆级豪华酒店，位于瘦西湖畔，环境清幽，园林式布局，客房分布在花园般的环境中，是游览瘦西湖后理想的休息之处。

### 2. 扬州瘦西湖温泉度假村

- **地址**：扬州市邗江区瘦西湖路18号
- **价格区间**：600-1500元/晚
- **特色**：五星级度假酒店，位于瘦西湖畔，拥有丰富的温泉资源，环境优美，设施豪华，是休闲度假的理想选择。

### 3. 如家酒店（扬州东关街店）

- **地址**：扬州市广陵区泰州路88号
- **价格区间**：180-320元/晚
- **特色**：经济型连锁酒店，位于东关街附近，交通便利，房间干净整洁，性价比高，适合预算有限的游客。

### 4. 扬州古城民宿聚集区

- **地址**：扬州市广陵区东关街、仁丰里周边（多家民宿）
- **价格区间**：200-500元/晚
- **特色**：古色古香的民宿聚集区，位于古城内，建筑风格古朴典雅，充满历史韵味，是体验扬州古城文化、感受江南慢生活的理想住宿选择。

### 5. 扬州运河畔精品酒店

- **地址**：扬州市广陵区古运河畔（多家精品酒店）
- **价格区间**：400-900元/晚
- **特色**：精品设计酒店，位于古运河畔，部分客房可俯瞰古运河美景，设计融合了中国古典元素与现代风格，是体验扬州“夜运河”魅力的理想住宿选择。

## 交通信息

- **机场**：扬州泰州国际机场，位于扬州市江都区丁沟镇，距市中心约30公里，已开通多条国内航线。
- **火车站**：扬州站（邗江区文昌西路），扬州东站（广陵区运河东路）。
- **公交**：公交线路发达，票价2元，部分旅游专线可直达瘦西湖、个园等主要景点。
- **出租车/网约车**：起步价10元（3公里），超过3公里后每公里2.4元。

## 旅游小贴士

1. **最佳旅游时间**：春季（3-5月）和秋季（9-11月）气候宜人，是游览扬州的最佳时节，尤其是3-4月烟花三月，不可错过。
2. **游览建议**：建议安排2-3天时间游览扬州，可将瘦西湖、个园、何园、大明寺、东关街等景点串联游览。
3. **特色体验**：体验扬州“早上皮包水”（吃早茶）和“晚上水包皮”（泡澡堂）的独特文化，品尝地道的淮扬美食。
4. **购物推荐**：东关街、彩衣街是扬州最繁华的旅游商业街，可以购买到各类扬州特产和纪念品，如扬州漆器、扬州剪纸、扬州三把刀等。
5. **注意事项**：扬州早茶时间较早（6:00-10:00），建议提前前往，避免排队；参观寺庙时注意着装得体，保持安静；瘦西湖游船是体验湖光水色的最佳方式，建议尝试。
