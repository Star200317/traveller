# 苏州旅游信息文档

## 城市概况

苏州，古称吴、吴都、吴中、东吴、吴门、平江，是江苏省辖地级市、经济强市，位于江苏省东南部，长江三角洲中部，太湖东岸，素有"人间天堂""东方威尼斯"之美誉。全市总面积8657.32平方公里，常住人口约1275万，下辖5个区4个县级市。苏州是一座有着2500多年建城史的国家历史文化名城，是中华文明的重要发祥地之一，自古就有"上有天堂，下有苏杭"之美誉。

苏州最著名的旅游名片当属苏州古典园林、周庄古镇、虎丘、寒山寺、金鸡湖等。苏州古典园林是中国私家园林的代表，已被列入世界文化遗产，其中拙政园、留园、网师园、沧浪亭等最为著名，被誉为"咫尺之内再造乾坤"。周庄古镇是中国第一水乡，始建于北宋元祐元年（1086年），距今已有930多年历史，保有大量明清时期的古建筑，是江南水乡古镇的典型代表。苏州属亚热带季风海洋性气候，四季分明，气候温和，雨量充沛，最佳旅游时间为3-5月和9-11月。

## 旅游景点

### 1. 拙政园

- **地址**：苏州市姑苏区东北街178号
- **门票**：90元/人（旺季），70元/人（淡季）
- **简介**：拙政园位于苏州市姑苏区，是苏州古典园林中面积最大的古典山水园林，也是中国四大名园之一，世界文化遗产。拙政园始建于明正德初年（16世纪初），距今已有500多年历史，由明代御史王献臣弃官回乡后兴建，取晋代潘岳《闲居赋》中"拙者之为政也"之意，命名为"拙政园"。

拙政园占地面积约5.2公顷，其中水面约占3/5，布局以水池为中心，亭台楼阁皆临水而建，具有浓郁的江南水乡特色。全园分为东、中、西三部分，中部是精华所在，主要景点包括远香堂、香洲、荷风四面亭、见山楼、小飞虹、枇杷园等，移步换景，美不胜收。拙政园的造园艺术堪称中国古典园林的典范，将山水、建筑、花木、书法、雕刻等艺术融为一体，充分体现了中国园林"虽由人作，宛自天开"的造园理念。建议游览时间2-3小时。

### 2. 虎丘

- **地址**：苏州市姑苏区虎丘山门内8号
- **门票**：70元/人（旺季），60元/人（淡季）
- **简介**：虎丘位于苏州市姑苏区，是苏州的城市象征，素有"吴中第一名胜""到苏州不游虎丘，乃憾事也"之美誉。虎丘海拔仅34.3米，但山体由千万年风雨侵蚀形成的独特岩石地貌，怪石嶙峋，气势不凡。虎丘始建于春秋时期，距今已有2500多年历史，是苏州历史文化的重要见证。

虎丘最著名的景观是云岩寺塔（俗称"虎丘塔"），建于五代后周显德六年（959年），落成于北宋建隆二年（961年），是一座七层八面的砖塔，高约48.2米。由于塔基土质松软，塔身自明代起逐渐倾斜，被誉为"中国比萨斜塔"，是苏州的标志性建筑之一。虎丘景区内还有剑池、千人石、真娘墓、断梁殿、冷香阁等历史文化遗迹，每一处都承载着深厚的历史文化内涵。苏轼曾言："到苏州不游虎丘，乃憾事也"，足见虎丘在苏州旅游中的地位。建议游览时间2-3小时。

### 3. 周庄古镇

- **地址**：苏州市昆山市周庄镇全福路43号
- **门票**：100元/人（日游），80元/人（夜游）
- **简介**：周庄古镇位于苏州市昆山市最南端，是中国第一水乡，也是江南六大古镇之首，始建于北宋元祐元年（1086年），距今已有930多年历史。周庄古镇保存有大量的明清建筑，古桥、古街、古宅、古巷错落有致，有水贯镇而过，形成了"井"字形的河道格局，居民依水而筑，粉墙黛瓦，小桥流水，如诗如画。

周庄古镇最著名的景观是双桥（世德桥和永安桥），两座桥联袂而筑，桥面一横一竖，桥洞一方一圆，形似一把古代的钥匙，故又名"钥匙桥"。1984年，著名画家陈逸飞以双桥为题材创作了油画《故乡的回忆》，在美国展出后引起轰动，次年被选为联合国首日封图案，使周庄古镇名扬四海。周庄古镇内还有沈万三故居、张厅、迷楼、叶楚伧故居、澄虚道院、全福讲寺等历史文化遗迹，是了解江南水乡文化、体验古镇慢生活的绝佳去处。建议游览时间半天至一天。

### 4. 寒山寺

- **地址**：苏州市姑苏区寒山寺弄24号
- **门票**：20元/人（成人），10元/人（学生/老人）
- **简介**：寒山寺位于苏州市姑苏区，始建于南朝萧梁天监年间（502-519年），距今已有1500多年历史，是中国著名的禅宗寺院，也是苏州最古老的寺庙之一。寒山寺因唐代诗人张继的七绝《枫桥夜泊》而闻名遐迩，诗中"姑苏城外寒山寺，夜半钟声到客船"成为千古绝唱，使寒山寺成为中国文化史上的重要符号。

寒山寺历经千年沧桑，多次毁建，现存建筑主要为清末重建。寺内主要建筑包括大雄宝殿、藏经楼、钟楼、碑廊、枫江楼等，其中大雄宝殿内供奉有释迦牟尼佛、迦叶尊者、阿难尊者三尊佛像，庄严肃穆。钟楼内悬挂有清代铸造的大钟，每年除夕之夜，寒山寺都会举行敲钟活动，钟声宏亮悠远，吸引大量游客前来聆听，祈求新的一年平安吉祥。寒山寺不仅是佛教圣地，也是了解苏州历史文化、体验江南禅意生活的绝佳去处。建议游览时间1.5-2小时。

### 5. 金鸡湖景区

- **地址**：苏州市吴中区星港街（金鸡湖西岸）
- **门票**：免费开放（部分景点收费）
- **简介**：金鸡湖景区位于苏州市吴中区（苏州工业园区内），是苏州最著名的现代旅游景区之一，也是开放式的国家AAAAA级旅游景区。金鸡湖水域面积7.4平方公里，比杭州西湖大1.87平方公里，湖畔建有现代化的商业街区、文化艺术中心、摩天轮、音乐喷泉等景观和设施，是苏州现代化都市风貌的典型代表。

金鸡湖景区最著名的景观是"金鸡湖音乐喷泉"和"东方之门"（俗称"秋裤楼"）。音乐喷泉每晚在固定时间开放，水柱随音乐节奏翩翩起舞，色彩绚丽，美轮美奂，是苏州最著名的夜景之一。东方之门是位于金鸡湖西岸的双子塔楼，高约301.8米，因造型酷似一条裤子而被网友戏称为"秋裤楼"，是苏州的新地标建筑之一。金鸡湖景区内还有李公堤、月光码头、文化艺术中心、摩天轮公园等现代化景点和休闲设施，是集观光、休闲、购物、餐饮于一体的综合性旅游区。建议游览时间半天至一天，傍晚时分前往可以同时欣赏日景和夜景。

## 美食餐厅

### 1. 松鹤楼（观前街店）

- **地址**：苏州市姑苏区观前街太监弄72号
- **推荐菜品**：松鼠鳜鱼、清溜虾仁、响油鳝糊
- **人均消费**：150-250元
- **简介**：松鹤楼始创于清乾隆二十二年（1757年），是苏州最古老的苏帮菜馆，也是商务部首批认定的"中华老字号"餐饮企业。以松鼠鳜鱼为代表的苏帮菜肴做工精细，口味清淡鲜美，是体验正宗苏帮菜的首选餐厅。

### 2. 得月楼（李公堤店）

- **地址**：苏州市吴中区金鸡湖大道李公堤2号
- **推荐菜品**：松鼠鳜鱼、蟹粉豆腐、苏州汤包
- **人均消费**：120-200元
- **简介**：得月楼始创于明嘉靖年间，是苏州最著名的苏帮菜馆之一，以正宗苏帮菜和精致的就餐环境而著称，是品尝苏州本帮菜、体验苏州饮食文化的绝佳去处。

### 3. 朱鸿兴面馆（观前街店）

- **地址**：苏州市姑苏区观前街宫巷63号
- **推荐菜品**：焖肉面、爆鱼面、枫镇大肉面
- **人均消费**：30-50元
- **简介**：朱鸿兴面馆始创于1938年，是苏州最著名的面馆，以苏式汤面著称，面条细滑筋道，汤头鲜美醇厚，是体验苏州早餐文化的绝佳去处。

### 4. 采芝斋（观前街总店）

- **地址**：苏州市姑苏区观前街91号
- **推荐菜品**：粽子糖、松子糖、苏式月饼
- **人均消费**：30-80元（购买伴手礼）
- **简介**：采芝斋始创于清光绪十年（1884年），是苏州最著名的老字号糖果店，以苏式糖果和糕点闻名，是苏州最具代表性的伴手礼之一。

### 5. 黄天源（观前街总店）

- **地址**：苏州市姑苏区观前街86号
- **推荐菜品**：黄天源糕团、桂花糕、猪油年糕
- **人均消费**：20-40元
- **简介**：黄天源始创于清道光元年（1821年），是苏州最著名的糕团店，以苏式糕团闻名，糕团软糯香甜，口感细腻，是苏州最具代表性的特色小吃之一。

## 住宿推荐

### 1. 苏州凯悦酒店

- **地址**：苏州市姑苏区华池街88号
- **价格区间**：1200-2500元/晚
- **特色**：五星级豪华酒店，位于金鸡湖东岸，部分客房可俯瞰金鸡湖美景，设施豪华，服务一流，是商务出行和高端旅游的理想选择。

### 2. 苏州南园宾馆

- **地址**：苏州市姑苏区带城桥路99号
- **价格区间**：800-1800元/晚
- **特色**：国宾馆级豪华酒店，位于南园遗址之上，环境清幽，文化氛围浓厚，是体验苏州古典园林文化的理想住宿选择。

### 3. 如家酒店（苏州观前街店）

- **地址**：苏州市姑苏区观前街碧凤坊38号
- **价格区间**：200-350元/晚
- **特色**：经济型连锁酒店，位于观前街核心地段，购物交通便利，房间干净整洁，性价比高，适合预算有限的游客。

### 4. 周庄古镇民宿

- **地址**：苏州市昆山市周庄镇内（多家民宿）
- **价格区间**：200-500元/晚
- **特色**：古色古香的古镇民宿，位于周庄古镇内，建筑风格古朴典雅，充满水乡韵味，是体验古镇慢生活的理想住宿选择。

### 5. 苏州古城区民宿聚集区

- **地址**：苏州市姑苏区平江路、山塘街周边
- **价格区间**：150-400元/晚
- **特色**：古城区有大量的家庭式民宿，价格实惠，主人热情好客，提供家常菜和旅游咨询服务，是体验苏州本地生活的经济之选。

## 交通信息

- **机场**：苏南硕放国际机场（位于无锡，距苏州市区约35公里），上海虹桥国际机场（距苏州市区约85公里）。
- **火车站**：苏州站（姑苏区苏站路），苏州北站（相城区南天成路），苏州园区站（吴中区星湖街）。
- **地铁**：苏州地铁目前有5条线路运营，覆盖主要城区和景点。
- **公交**：公交线路发达，票价2元，部分旅游专线可直达主要景点。
- **出租车/网约车**：起步价10元（3公里），超过3公里后每公里2元。

## 旅游小贴士

1. **最佳旅游时间**：春季（3-5月）和秋季（9-11月）气候宜人，是游览苏州的最佳时节。
2. **游览建议**：建议安排2-3天时间游览苏州，可将拙政园、虎丘、平江路、山塘街等景点串联游览。
3. **特色体验**：乘坐手摇船游览古运河，参观古典园林了解中国古代造园艺术，品尝地道的苏帮菜和苏式汤面。
4. **购物推荐**：观前街、平江路、山塘街是苏州最繁华的旅游商业街，可以购买到各类苏州特产和纪念品。
5. **注意事项**：苏州古典园林内禁止吸烟、大声喧哗；品尝苏式汤面时，记得体验"过桥"吃法；周庄古镇日游门票较贵，可以选择夜游或住在古镇内次日续游。
