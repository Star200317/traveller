# 广州旅游信息文档

## 城市概况

广州，简称“穗”，别称羊城、花城、五羊，是广东省省会，副省级市、国家中心城市，位于广东省中南部，珠江三角洲北缘，素有“千年商都”“美食之都”之美誉。全市总面积7434.4平方公里，常住人口约1870万，下辖11个区。广州是一座有着2200多年建城史的国家历史文化名城，是中华文明的重要发祥地之一，自古就有“食在广州”“花城广州”之美誉。

广州最著名的旅游名片当属广州塔、白云山、长隆野生动物世界、陈家祠、沙面等。广州塔是广州最具标志性的现代景观，塔高600米，是中国第一、世界第二高塔，被誉为“小蛮腰”。白云山是广州的“市肺”，素有“羊城第一秀”之美誉。广州属亚热带海洋性季风气候，温暖湿润，雨量充沛，最佳旅游时间为10-12月和3-5月。

## 旅游景点

### 1. 广州塔（小蛮腰）

- **地址**：广州市海珠区阅江西路222号
- **门票**：150-298元/人（根据观光层不同）
- **简介**：广州塔位于广州市海珠区阅江西路，是一座以观光旅游为主的大型电视塔，也是国家AAAA级旅游景区。广州塔塔高600米，其中主体塔高454米，天线桅杆高146米，是中国第一、世界第二高塔，因其腰身纤细、造型独特，被市民亲切地称为“小蛮腰”。

广州塔占地面积约17.6万平方米，总建筑面积约11.4万平方米，塔内设有多个观光层，其中488米户外观景平台是世界上最高的户外观景平台，可360度俯瞰广州全城和珠江美景。塔内还设有460米摩天轮、480米户外观景平台、424米创意餐厅、407米休闲娱乐厅等多个功能区域，是集观光、餐饮、娱乐、科普于一体的综合性旅游塔。建议游览时间2-3小时，傍晚时分前往可以同时欣赏日景和夜景。

### 2. 白云山风景名胜区

- **地址**：广州市白云区广园中路801号
- **门票**：5元/人（进山费），部分景点单独收费
- **简介**：白云山位于广州市白云区，是南粤名山之一，也是国家AAAA级旅游景区。白云山因山间常有白云飘绕而得名，最高点摩星岭海拔382米，是广州的“市肺”和“羊城第一秀”，自古就有“羊城第一秀”之美誉。

白云山占地面积约20.98平方公里，由30多座山峰组成，主要景点包括鸣春谷、云台花园、明珠楼、摩星岭、云溪生态公园、雕塑公园等，其中鸣春谷是中国最大的天然鸟笼，内有鸟类150余种，5000余只，是爱鸟人士的绝佳去处。云台花园是白云山最具代表性的花园，种植有各类花卉数十万株，四季花开不断，美不胜收。建议游览时间半天至一天。

### 3. 长隆野生动物世界

- **地址**：广州市番禺区汉溪大道东299号
- **门票**：300元/人（成人），210元/人（儿童/老人）
- **简介**：长隆野生动物世界位于广州市番禺区，是长隆旅游度假区的重要组成部分，也是国家AAAAA级旅游景区。长隆野生动物世界占地面积约2000余亩，放养着以“十大世界珍稀动物国宝”为代表的500余种、20000余只珍稀动物，是中国最大的野生动物园之一。

长隆野生动物世界最著名的景观是“自驾区”和“步行区”两大游览区，游客可以选择自驾或乘坐园区小火车游览放养区的各种野生动物，包括长颈鹿、斑马、羚羊、犀牛、狮子、老虎等，体验与动物近距离接触的乐趣。园内的“大熊猫中心”饲养有数只大熊猫，憨态可掬，深受小朋友们的喜爱。长隆野生动物世界不仅是一个野生动物园，也是一个集动物保护、科普教育、游乐休闲于一体的综合性主题公园。建议游览时间1-2天。

### 4. 陈家祠（陈氏书院）

- **地址**：广州市荔湾区中山七路恩龙里34号
- **门票**：10元/人（成人），5元/人（学生/老人）
- **简介**：陈家祠位于广州市荔湾区，是清代广东陈氏宗族合族合资兴建的宗族祠书院，也是广东现存规模最大、保存最完好的传统岭南祠堂式建筑，素有“岭南建筑艺术瑰宝”之美誉，国家AAAA级旅游景区。

陈家祠始建于清光绪十四年（1888年），落成于光绪二十年（1894年），距今已有130多年历史。祠内建筑面积约1.3万平方米，主要建筑包括前门、前殿、中殿、后殿及东西两厢，建筑装饰精巧绝伦，广泛采用了木雕、石雕、砖雕、陶塑、灰塑、铜铁铸等多种工艺，被誉为“岭南建筑艺术的瑰宝”。陈家祠不仅是宗祠建筑的代表，也是了解岭南建筑艺术、体验广东宗族文化的最佳去处。建议游览时间2-3小时。

### 5. 沙面历史文化街区

- **地址**：广州市荔湾区沙面街道（沿沙面南街、沙面北街）
- **门票**：免费开放
- **简介**：沙面位于广州市荔湾区，是珠江冲积而成的沙洲，故名“沙面”，也是广州最具代表性的历史文化街区，素有“广州西贡”“露天建筑博物馆”之美誉。沙面始建于清咸丰九年（1859年），是英法联军占领广州后的英法租界，至今已有160多年历史。

沙面占地面积约0.3平方公里，岛上保留有大量的西式建筑，包括哥特式、巴洛克式、券廊式、新古典式等多种风格，其中沙面天主堂（露德圣母堂）、沙面基督堂、法国领事馆旧址、英国领事馆旧址等是最具代表性的建筑。沙面古木参天，环境清幽，是拍摄婚纱照、体验广州近代史的绝佳去处。夜晚的沙面格外迷人，古街灯火辉煌，江景璀璨，是体验广州夜生活的绝佳去处。建议傍晚时分前往，可以同时欣赏日景和夜景，游览时间2-3小时。

## 美食餐厅

### 1. 广州酒家（文昌总店）

- **地址**：广州市荔湾区文昌南路2号
- **推荐菜品**：文昌鸡、烧鹅、虾饺
- **人均消费**：100-200元
- **简介**：广州酒家始创于1935年，是广州最著名的餐饮品牌之一，以正宗粤菜和精致点心为主，文昌鸡是广州酒家的招牌菜，皮脆肉嫩，鲜香味美，是体验正宗粤菜的首选餐厅。

### 2. 点都德（天河城店）

- **地址**：广州市天河区天河路208号天河城6楼
- **推荐菜品**：虾饺、干蒸烧卖、叉烧包
- **人均消费**：60-100元
- **简介**：点都德是广州最具代表性的茶楼之一，以正宗广式点心和早茶为主，虾饺皮薄馅大，汁水饱满，是体验广州“吃早茶”文化的绝佳去处。

### 3. 炳胜品味（珠江新城店）

- **地址**：广州市天河区花城大道68号
- **推荐菜品**：脆皮烧肉、清蒸石斑鱼、白切鸡
- **人均消费**：120-220元
- **简介**：炳胜品味是广州最具代表性的粤菜餐厅之一，以正宗粤菜和海鲜为主，做工精细，口味清淡鲜美，是体验广州本帮菜的首选餐厅。

### 4. 陈添记鱼皮（宝华路总店）

- **地址**：广州市荔湾区宝华路83号
- **推荐菜品**：鱼皮、艇仔粥、猪脚姜
- **人均消费**：20-40元
- **简介**：陈添记鱼皮是广州最有名的传统小吃店，创立已有30多年，以鱼皮爽脆、粥底绵滑而著称，是广州人最喜爱的宵夜之一。

### 5. 广州小吃聚集区（上下九步行街、北京路步行街）

- **地址**：广州市荔湾区上下九步行街、越秀区北京路步行街
- **推荐菜品**：虾饺、干蒸烧卖、叉烧包、肠粉、云吞面、双皮奶
- **人均消费**：40-80元
- **简介**：上下九步行街和北京路步行街是广州最著名的小吃聚集区，汇聚了广州各种特色小吃和老字号餐厅，是品尝广州美食、体验羊城风情的绝佳去处。

## 住宿推荐

### 1. 广州四季酒店

- **地址**：广州市天河区珠江西路5号
- **价格区间**：1500-3500元/晚
- **特色**：超五星级豪华酒店，位于珠江新城核心地段，部分客房可俯瞰珠江美景和小蛮腰，设施豪华，服务一流，是商务出行和高端旅游的理想选择。

### 2. 广州白天鹅宾馆

- **地址**：广州市荔湾区沙面街道沙面南街1号
- **价格区间**：1000-2500元/晚
- **特色**：五星级豪华酒店，位于沙面岛上，是中国第一家中外合作的五星级酒店，装修典雅，环境清幽，服务优质，是广州市标志性豪华酒店之一。

### 3. 如家酒店（广州北京路店）

- **地址**：广州市越秀区北京路312号
- **价格区间**：200-400元/晚
- **特色**：经济型连锁酒店，位于北京路步行街核心地段，购物交通便利，房间干净整洁，性价比高，适合预算有限的游客。

### 4. 广州沙面民宿聚集区**

- **地址**：广州市荔湾区沙面街道内（多家民宿）
- **价格区间**：200-600元/晚
- **特色**：历史建筑改建的民宿聚集区，位于沙面岛上，建筑风格充满欧陆风情，是体验广州近代史、感受沙面慢生活的理想住宿选择。

### 5. 广州长隆酒店**

- **地址**：广州市番禺区汉溪大道东299号（长隆度假区内）
- **价格区间**：800-2000元/晚
- **特色**：主题度假酒店，位于长隆旅游度假区内，部分客房可看到野生动物园的白虎、大熊猫等，是亲子游的理想住宿选择。

## 交通信息

- **机场**：广州白云国际机场，位于广州市白云区人和镇，距市中心约28公里，已开通国内外多条航线。
- **火车站**：广州站（越秀区环市西路），广州东站（天河区东站路），广州南站（番禺区石壁街道），广州北站（花都区）。
- **地铁**：广州地铁目前有16条线路运营，覆盖主要城区和景点。
- **公交**：公交线路发达，票价2元，部分旅游专线可直达主要景点。
- **出租车/网约车**：起步价12元（2.5公里），超过2.5公里后每公里2.6元。
- **珠江夜游**：从天字码头、大沙头码头乘船可欣赏珠江两岸夜景，是游览广州夜景的主要方式之一。

## 旅游小贴士

1. **最佳旅游时间**：秋季（10-12月）和春季（3-5月）气候宜人，是游览广州的最佳时节。
2. **游览建议**：建议安排3-4天时间游览广州，可将广州塔、白云山、长隆野生动物世界、陈家祠、沙面、北京路步行街等景点串联游览。
3. **特色体验**：体验广州“吃早茶”文化（喝早茶、吃点心），品尝地道的粤菜和广式小吃，乘坐珠江夜游船欣赏两岸夜景。
4. **购物推荐**：北京路步行街、上下九步行街、天河城、正佳广场是广州最繁华的购物区，可以购买到各类商品和广州特产（如广式月饼、鸡仔饼、腊味等）。
5. **注意事项**：广州人口味清淡，粤菜注重食材原味，口味偏清淡鲜美；夏季炎热多雨，需做好防暑降温和防雨准备；品尝海鲜时注意选择正规餐厅，避免被宰。
