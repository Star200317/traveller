# 大同旅游信息文档

## 城市概况

大同，别称云中、平城，是山西省省域副中心城市，位于山西省最北端，地处晋、冀、蒙三省区交界处，素有"三代京华、两朝重镇"之美誉。全市总面积14176平方公里，常住人口约310万，下辖4区6县。大同是一座有着2400多年建城史的国家历史文化名城，是中华文明的重要发祥地之一，自古就是军事重镇和战略要地。

大同最著名的旅游名片当属云冈石窟、悬空寺、华严寺、九龙壁等。云冈石窟是中国四大石窟之一，也是世界文化遗产，始建于北魏兴安二年（453年），历经60余年建成，现存主要洞窟45个，大小石雕造像51000余尊，是中国佛教艺术第一个巅峰时期的经典之作。悬空寺始建于北魏后期（约471-523年），是一座建在悬崖峭壁上的寺院，以"奇、悬、巧"著称，是中国古代建筑艺术的瑰宝。大同属温带大陆性季风气候，四季分明，夏季凉爽，是理想的避暑胜地，最佳旅游时间为5-10月。

## 旅游景点

### 1. 云冈石窟

- **地址**：大同市云冈区云冈镇云冈路1号
- **门票**：120元/人（旺季），100元/人（淡季）
- **简介**：云冈石窟位于大同市西16公里的武周山南麓，是中国四大石窟之一，也是世界文化遗产、国家AAAAA级旅游景区。云冈石窟始建于北魏兴安二年（453年），由高僧昙曜主持开凿，历经60余年建成，现存主要洞窟45个，大小石雕造像51000余尊，是中国佛教艺术第一个巅峰时期的经典之作。

云冈石窟的造像气势宏伟，内容丰富，继承了秦汉以来的艺术传统，又吸收了外来艺术精华，展现出中国佛教艺术由"胡貌梵相"向"改梵为夏"演进的历史过程。其中第20窟的露天大佛是云冈石窟的标志性造像，佛像高13.7米，面部丰满圆润，神态庄严慈祥，是北魏佛像艺术的杰出代表。第5、6窟是云冈石窟中规模最大、内容最丰富的双窟，窟内浮雕精美绝伦，堪称北魏佛教艺术的百科全书。云冈石窟不仅是中国古代雕刻艺术的宝库，也是研究北魏历史、佛教文化、建筑艺术的重要实物资料。建议游览时间3-4小时。

### 2. 悬空寺

- **地址**：大同市浑源县悬空寺景区
- **门票**：125元/人（含登临费）
- **简介**：悬空寺位于大同市浑源县恒山金龙峡西侧翠屏峰的半崖峭壁之上，始建于北魏后期（约471-523年），距今已有约1500年历史，是中国仅存的佛、道、儒三教合一的独特寺庙。悬空寺以"奇、悬、巧"著称，整座寺院建在距地面约50米的悬崖峭壁之上，利用力学原理半插飞梁为基，巧借岩石暗托，梁柱上下一体，廊栏左右相连，虚实相生，错落有致。

悬空寺建筑面积虽仅152.5平方米，但布局紧凑，设计精巧，寺内建有寺院、禅房、佛堂、三佛殿、太乙殿、关帝庙、鼓楼、钟楼、伽蓝殿、送子观音殿、地藏王菩萨殿、千手观音殿等40余处建筑，最高处的三教殿距离地面约50米。寺内供奉有佛教的释迦牟尼、道教的太上老君、儒家的孔子，三教共处一寺，和谐共存，充分体现了中华文化的包容性和融合性。悬空寺历经1500余年的风雨沧桑，仍巍然屹立，是中国古代建筑艺术的瑰宝，也是世界建筑史上的奇迹。建议游览时间2-3小时。

### 3. 华严寺

- **地址**：大同市平城区下寺坡街459号
- **门票**：50元/人（成人），25元/人（学生/老人）
- **简介**：华严寺位于大同市平城区，始建于辽重熙七年（1038年），是我国现存年代较早、保存较完整的一座辽金寺庙建筑群，也是全国重点文物保护单位。华严寺坐西向东，与一般汉地寺庙坐北朝南的布局迥然不同，这是辽代寺庙的典型布局特征，反映了辽代契丹族"崇拜太阳、以东为尊"的文化传统。

华严寺分为上寺和下寺两部分，上寺以大雄宝殿为中心，下寺以薄伽教藏殿为中心。大雄宝殿始建于辽代，后毁于战火，现存建筑为金天眷三年（1140年）重建，建筑面积达1559平方米，是现存辽金时期最大的佛殿之一。薄伽教藏殿建于辽重熙七年（1038年），是华严寺的藏经殿，殿内保存有辽代塑像29尊，其中合掌露齿菩萨塑像被誉为"东方维纳斯"，面容秀丽，体态丰满，姿态优美，是中国古代雕塑艺术的杰出代表。薄伽教藏殿内还保存有重楼式藏经柜38间，是辽代建筑的典型代表，被誉为"辽代艺术博物馆"。建议游览时间2-3小时。

### 4. 九龙壁

- **地址**：大同市平城区大东街18号
- **门票**：10元/人（成人），5元/人（学生/老人）
- **简介**：九龙壁位于大同市平城区大东街，建于明洪武二十五年（1392年），是明太祖朱元璋第十三子朱桂王府前的照壁，也是中国现存规模最大、建筑年代最早的琉璃照壁，比北京故宫九龙壁早350年，比北京北海九龙壁早450年。九龙壁长45.5米，高8米，厚2.02米，壁上建有九条巨龙，颜色分别为：黄、紫、黑、赭、蓝、白、绿、红、青，九条龙神态各异，栩栩如生，壁前倒影池更增添了九龙壁的灵动之美。

九龙壁的整体建筑由壁座、壁身、壁顶三部分组成，壁座为须弥座式，束腰部位雕刻有狮、虎、象、鹿、马等动物图案，姿态各异，生动传神；壁身是九龙壁的主体部分，由426块特制琉璃构件拼砌而成，九条巨龙在波涛云海中翻腾，气势磅礴；壁顶为仿木结构琉璃壁顶，檐下斗拱为琉璃仿木构件，色彩绚丽，工艺精湛。九龙壁不仅是一件伟大的建筑艺术作品，也是研究明代琉璃工艺、雕刻艺术、建筑技术的重要实物资料。建议游览时间1小时左右。

### 5. 恒山

- **地址**：大同市浑源县大磁窑村
- **门票**：55元/人（入山费），125元/人（含悬空寺）
- **简介**：恒山位于大同市浑源县境内，是中国五岳之一的北岳，与东岳泰山、西岳华山、南岳衡山、中岳嵩山并称五岳。恒山主峰天峰岭海拔2016.1米，山势陡峭，沟谷深邃，道路险峻，自古就有"人天北柱""绝塞名山"之美誉。恒山是著名的道教圣地，相传道教八仙之一的张果老曾在恒山修道炼丹，山上有大量与张果老相关的遗迹和传说。

恒山景区内有大量历史文化遗迹和自然景观，包括悬空寺、北岳庙、纯阳宫、九天宫、十王殿、会仙府、文昌阁等。其中北岳庙是恒山的主庙，始建于北魏，是祭祀北岳大帝的场所，庙内古松参天，环境清幽，是恒山最重要的道教建筑群。恒山的自然风光也十分壮丽，主峰天峰岭巍峨耸立，山间云雾缭绕，松涛阵阵，泉水潺潺，是登山揽胜、修身养性的绝佳去处。建议游览时间半天至一天。

## 美食餐厅

### 1. 大同刀削面（老柴家）

- **地址**：大同市平城区仿古街32号
- **推荐菜品**：刀削面、过油肉、浑源凉粉
- **人均消费**：20-40元
- **简介**：大同刀削面是山西面食的代表之一，以刀功精湛、面片筋道、卤汁鲜美而著称。老柴家刀削面是大同最有名的面食店，已有30多年历史，是品尝正宗大同刀削面的绝佳去处。

### 2. 浑源凉粉

- **地址**：大同市浑源县永安西街18号
- **推荐菜品**：浑源凉粉、豆腐干、烧饼
- **人均消费**：10-25元
- **简介**：浑源凉粉是大同浑源县的特色小吃，用土豆淀粉制成凉粉，搭配特制的辣椒油、蒜泥、醋等调料，酸辣可口，清爽解暑，是夏季消暑的佳品，也是浑源县最具代表性的特色小吃。

### 3. 大同涮羊肉

- **地址**：大同市平城区魏都大道88号
- **推荐菜品**：涮羊肉、羊肉串、烧饼
- **人均消费**：80-150元
- **简介**：大同涮羊肉是大同的特色美食，选用大同及周边地区放养的羔羊，肉质鲜嫩，膻味小，用传统铜锅涮煮，搭配芝麻酱、韭菜花、腐乳等蘸料，鲜香味美，是冬季进补的佳品。

### 4. 大同黄糕

- **地址**：大同市平城区大西街56号（小吃摊聚集区）
- **推荐菜品**：黄糕、油糕、素糕
- **人均消费**：10-20元
- **简介**：黄糕是大同的传统小吃，用黄米面制成，口感软糯，香甜可口。黄糕可以素吃（蘸白糖或蜂蜜），也可以油炸（油糕），是大同人最喜爱的传统小吃之一。

### 5. 大同兔头

- **地址**：大同市平城区新建北路102号
- **推荐菜品**：麻辣兔头、五香兔头、兔腿
- **人均消费**：30-60元
- **简介**：兔头是大同的特色小吃，用多种香料卤制而成，肉质鲜嫩，味道醇香，是大同人最喜爱的夜宵之一。麻辣兔头香辣扑鼻，五香兔头香味浓郁，令人回味无穷。

## 交通信息

- **机场**：大同云冈国际机场，位于大同市云州区机场路1号，距市中心约15公里，已开通多条国内航线。
- **火车站**：大同站（平城区站前街），大同南站（平城区开源街）。
- **公交**：公交线路发达，票价1-2元，部分旅游专线可直达云冈石窟、恒山等景点。

## 旅游小贴士

1. **最佳旅游时间**：夏季（6-8月）气候凉爽，是游览大同的最佳时节；秋季（9-10月）天高气爽，也适合出游。
2. **游览建议**：建议安排2-3天时间游览大同，可将云冈石窟、悬空寺、华严寺、九龙壁、恒山等景点串联游览。
3. **特色体验**：品尝地道的山西面食，参观云冈石窟感受北魏佛教艺术，登临悬空寺体验古代建筑奇迹。
4. **购物推荐**：大同市区的仿古街、大西街是购买山西特产和纪念品的好去处，可以购买到刀削面、老陈醋、浑源凉粉等大同特产。
5. **注意事项**：大同气候干燥，需注意多喝水；参观寺庙时注意着装得体，保持安静；云冈石窟内禁止拍照。
