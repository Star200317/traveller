# 合肥旅游信息文档

## 城市概况

合肥，简称"庐"或"合"，古称庐州、合州、金斗、汝阴，是安徽省省会，位于安徽省中部，长江淮河之间，巢湖之滨，素有"三国故地""包公故里""科教基地"之美誉。全市总面积11445.1平方公里，常住人口约950万，下辖4个区4个县1个县级市。合肥是一座有着2200多年建城史的国家科技创新型试点城市，也是中华文明的重要发祥地之一。

合肥最著名的旅游名片当属包公祠、三河古镇、巢湖、徽园、安徽博物院等。包公祠是为纪念北宋名臣包拯而建的祠堂，始建于明弘治元年（1488年），是合肥最具标志性的历史文化景点。巢湖是中国五大淡水湖之一，湖光山色美不胜收，被誉为"皖中明珠"。合肥属亚热带季风气候，四季分明，气候温和，雨量充沛，最佳旅游时间为3-5月和9-11月。

## 旅游景点

### 1. 包公祠（包孝肃公祠）

- **地址**：合肥市包河区芜湖路72号（包公文化园内）
- **门票**：50元/人（成人），25元/人（学生/老人）
- **简介**：包公祠位于合肥市包河区包公文化园内，是为纪念北宋名臣包拯（包公）而建的祠堂，也是合肥最具标志性的历史文化景点，国家AAAA级旅游景区。包公祠始建于明弘治元年（1488年），历经各代修葺扩建，形成了包括包公祠、包公墓、清风阁、浮庄、九狮广场等在内的包公文化园。

包公祠占地面积约34.5公顷，主要建筑包括照壁、山门、正殿、东西配殿、廉泉井、流芳亭等，其中正殿内供奉有包公塑像，像高约3米，正襟危坐，威严庄重，是包公文化的象征。包公墓位于包公祠南侧，是包拯及其家族的墓园，墓园内植有松柏，环境清幽，是缅怀包公、了解包公文化的重要场所。包公文化园不仅是历史文化景点，也是全国爱国主义教育示范基地，是了解包公"清心为治本，直道是身谋"廉洁精神的最佳去处。建议游览时间2-3小时。

### 2. 三河古镇

- **地址**：合肥市肥西县三河镇三河路1号
- **门票**：免费开放（部分景点收费，联票80元/人）
- **简介**：三河古镇位于合肥市肥西县南端，距合肥市区约40公里，是中国历史文化名镇，也是国家AAAA级旅游景区。三河古镇因丰乐河、杭埠河、小南河三水交汇而得名，距今已有2500多年历史，素有"皖中水乡""春秋古镇"之美誉。

三河古镇占地面积约4.7平方公里，其中古镇核心保护区面积约1.3平方公里，保留了大量的明清建筑和民国建筑，包括古民居、古桥、古街、古巷、古庙、古战场等，是了解皖中水乡文化、体验古镇慢生活的绝佳去处。古镇最著名的景观包括万年台、忠武将军府、鹤庐、刘同兴隆庄、杨振宁旧居、孙立人故居等，其中杨振宁旧居是诺贝尔物理学奖得主杨振宁先生在抗战时期居住过的地方，现已成为三河古镇最重要的历史文化景点之一。建议游览时间半天至一天。

### 3. 巢湖风景名胜区

- **地址**：合肥市巢湖市巢湖路1号（巢湖之滨）
- **门票**：免费开放（部分景点收费）
- **简介**：巢湖位于合肥市南部，是中国五大淡水湖之一，也是合肥最具代表性的自然景观，素有"皖中明珠""八百里湖天"之美誉。巢湖东西长55公里，南北宽22公里，水域面积约750平方公里，湖岸线长约180公里，是合肥的"母亲湖"。

巢湖风景名胜区包括湖面、湖岛、湖岸三部分，其中湖岛包括姥山岛、孤山岛、鞋山岛等，姥山岛是巢湖中最大的岛屿，岛上有姥山塔、文峰塔、圣妃庙等历史文化遗迹。巢湖不仅自然风光优美，还有深厚的历史文化底蕴，相传是上古时期有巢氏的居地，也是三国时期魏吴争霸的战场之一。巢湖还是著名的渔业基地，湖中盛产银鱼、白虾、螃蟹等水产品，是品尝巢湖海鲜的绝佳去处。建议游览时间半天至一天。

### 4. 徽园

- **地址**：合肥市蜀山区繁华大道276号
- **门票**：20元/人（成人），10元/人（学生/老人）
- **简介**：徽园位于合肥市蜀山区，是安徽省最大的仿明清建筑群，也是国家AAAA级旅游景区。徽园始建于1999年，是为庆祝新中国成立50周年而建，占地面积约20公顷，集中展示了安徽17个地市的风貌特色和历史文化，素有"不到徽园，不知安徽"之美誉。

徽园的建筑风格以明清徽派建筑为主，融合了安徽各地特色建筑元素，主要景点包括亳州花戏楼、黄山碑廊、安庆振风塔、滁州醉翁亭、阜阳文峰塔、马鞍山采石矶等，其中黄山碑廊内刻有当代书法名家书写的《黄山七十二峰图》和《黄山古诗百首》，工艺精湛，文化价值极高。徽园内还有安徽名人馆、安徽科技馆、安徽美术馆等多处文化设施，是了解安徽历史文化、体验安徽各地风情的绝佳去处。建议游览时间2-3小时。

### 5. 安徽博物院

- **地址**：合肥市蜀山区怀宁路268号
- **门票**：免费开放（需提前预约）
- **简介**：安徽博物院位于合肥市蜀山区，是安徽省最大的综合性博物馆，也是国家一级博物馆。博物院占地面积约6.2万平方米，建筑面积约4.1万平方米，收藏有各类文物和标本40余万件，其中珍贵文物约10万余件，是了解安徽历史文化的重要窗口。

安徽博物院的馆藏文物涵盖了旧石器时代至近现代的各个历史时期，其中以商周青铜器、春秋战国漆器、汉代铜镜、唐代瓷器、宋代金银器、明代徽州文书等最具特色。镇馆之宝包括"商兽面纹铜尊""春秋"蔡侯"铜编钟""唐三彩骆驼载乐俑""北宋金边玛瑙碗"等，每一件都是国之瑰宝。博物院常设展览包括"安徽文明史陈列""徽州古建筑""安徽古生物化石""安徽名人馆"等，系统展示了安徽地区的历史发展脉络和文化特色。建议游览时间3-4小时。

## 美食餐厅

### 1. 庐州烤鸭店（宿州路总店）

- **地址**：合肥市庐阳区宿州路106号
- **推荐菜品**：庐州烤鸭、鸭油汤包、鸭油烧饼
- **人均消费**：40-80元
- **简介**：庐州烤鸭店始创于清光绪年间，是合肥最著名的老字号餐厅，以庐州烤鸭为代表作，烤鸭皮脆肉嫩，鸭油汤包汤汁鲜美，是体验合肥本帮菜的首选餐厅。

### 2. 刘鸿盛（人民广场总店）

- **地址**：合肥市庐阳区人民广场东侧
- **推荐菜品**：鸭油汤包、鸭油烧饼、赤豆糊
- **人均消费**：30-60元
- **简介**：刘鸿盛始创于清光绪年间，是合肥最著名的小吃店，以鸭油汤包和鸭油烧饼著称，汤包皮薄馅大，汤汁鲜美，是合肥最具代表性的特色小吃之一。

### 3. 三河米饺（三河古镇内多家店）

- **地址**：合肥市肥西县三河古镇内（多家小吃店）
- **推荐菜品**：三河米饺、酥鸭、三河小炒
- **人均消费**：20-40元
- **简介**：三河米饺是三河古镇的传统小吃，用米粉制成饺皮，以五花肉、豆腐、马蹄等为馅，油炸而成，外皮酥脆，内馅鲜美，是三河古镇最具代表性的特色小吃。

### 4. 巢湖银鱼（巢湖畔多家餐厅）

- **地址**：合肥市巢湖市巢湖路（多家海鲜餐厅）
- **推荐菜品**：银鱼蒸蛋、白虾豆腐、湖蟹豆腐
- **人均消费**：80-150元
- **简介**：巢湖银鱼是巢湖最具代表性的水产品，肉质鲜嫩，味道清甜，用银鱼蒸蛋、银鱼炒蛋等都是巢湖周边餐厅的招牌菜，是品尝巢湖鲜味的绝佳去处。

### 5. 合肥小龙虾（宁国路小龙虾一条街）

- **地址**：合肥市包河区宁国路（小龙虾一条街）
- **推荐菜品**：麻辣小龙虾、蒜蓉小龙虾、十三香小龙虾
- **人均消费**：60-120元
- **简介**：宁国路小龙虾一条街是合肥最著名的小龙虾聚集地，沿途有数十家小龙虾专营店，麻辣鲜香，是合肥人最喜爱的夜宵之一。

## 住宿推荐

- **特色**：五星级豪华酒店，位于万象城商圈核心地段，装修典雅豪华，设施一流，服务优质，是商务出行和高端旅游的理想选择。

### 2. 合肥元一希尔顿酒店

- **地址**：合肥市瑶海区胜利路198号
- **价格区间**：800-1800元/晚
- **特色**：五星级豪华酒店，位于胜利路商务区，紧邻元一时代广场，设施豪华，服务一流，是合肥市标志性豪华酒店之一。

### 3. 如家酒店（合肥包公祠店）

- **地址**：合肥市包河区芜湖路128号

- **特色**：经济型连锁酒店，位于包公祠附近，交通便利，房间干净整洁，性价比高，适合预算有限的游客。

### 4. 三河古镇民宿聚集区

- **地址**：合肥市肥西县三河古镇内（多家民宿）

### 5. 巢湖畔度假酒店

- **地址**：合肥市巢湖市巢湖路（多家度假酒店）
- **价格区间**：300-800元/晚
- **特色**：度假型酒店，位于巢湖畔，环境清幽，空气清新，是游览巢湖后理想的休息之处。

## 交通信息

- **机场**：合肥新桥国际机场，位于合肥市蜀山区新桥大道1号，距市中心约31公里，已开通国内外多条航线。
- **火车站**：合肥站（瑶海区站前路），合肥南站（包河区龙川路），合肥西站（蜀山区长江西路）。
- **地铁**：合肥地铁目前有5条线路运营，覆盖主要城区和景点。
- **公交**：公交线路发达，票价2元，部分旅游专线可直达主要景点。
- **出租车/网约车**：起步价10元（3公里），超过3公里后每公里2.5元。

## 旅游小贴士

1. **最佳旅游时间**：春季（3-5月）和秋季（9-11月）气候宜人，是游览合肥的最佳时节。
2. **游览建议**：建议安排2-3天时间游览合肥，可将包公祠、三河古镇、巢湖、徽园、安徽博物院等景点串联游览。
3. **特色体验**：品尝地道的庐州烤鸭和鸭油汤包，参观安徽博物院了解安徽历史文化，逛三河古镇体验皖中水乡风情。
4. **购物推荐**：淮河路步行街、三里庵国购广场是合肥最繁华的购物区，可以购买到各类商品和安徽特产。
5. **注意事项**：合肥夏季炎热，冬季阴冷，需做好相应防护；品尝小龙虾时，注意选择正规餐厅，避免被宰。
