# 厦门旅游信息文档

## 城市概况

厦门，简称“鹭”，别称鹭岛、鹭门、鹭江，是福建省辖副省级市、计划单列市，位于福建省东南部，台湾海峡西岸，素有“海上花园”“鹭岛明珠”之美誉。全市总面积1700.61平方公里，常住人口约530万，下辖6个区。厦门是一座有着1500多年建城史的国家经济特区，是海峡西岸经济区的核心城市，自古就有“城在海上，海在城中”之美誉。

厦门最著名的旅游名片当属鼓浪屿、南普陀寺、厦门大学、环岛路、曾厝垵等。鼓浪屿是中国最著名的历史文化街区之一，也是世界文化遗产，素有“海上花园”“音乐之岛”之美誉。厦门大学是中国最美的大学之一，依山傍海，建筑宏伟，被誉为“山海花园大学”。厦门属亚热带海洋性季风气候，温暖湿润，雨量充沛，最佳旅游时间为3-5月和9-11月。

## 旅游景点

### 1. 鼓浪屿风景名胜区

- **地址**：厦门市思明区鼓浪屿（需从轮渡码头乘船）
- **门票**：鼓浪屿免费开放，部分景点联票100元/人（含日光岩、皓月园、菽庄花园、风琴博物馆、刻字博物馆）
- **简介**：鼓浪屿位于厦门市思明区，是厦门湾中的一座小岛，与世界文化遗产，国家AAAAA级旅游景区。鼓浪屿因岛西南端海蚀洞受浪潮冲击，声如擂鼓，明朝时雅化为“鼓浪屿”，距今已有近500年历史，素有“海上花园”“音乐之岛”之美誉。

鼓浪屿占地面积约1.91平方公里，岛上保存有大量的领事馆、教堂、私人别墅等历史建筑，涵盖哥特式、巴洛克式、折衷主义、中西合璧式等多种风格，被誉为“万国建筑博览馆”。岛上有日光岩、菽庄花园、皓月园、风琴博物馆、国际刻字博物馆等多处历史文化景点，其中日光岩是鼓浪屿的最高点，海拔92.7米，登顶可俯瞰厦门全城和台湾海峡，是鼓浪屿最著名的景观之一。建议游览时间半天至一天。

### 2. 南普陀寺

- **地址**：厦门市思明区思明南路515号
- **门票**：免费开放（需提前预约）
- **简介**：南普陀寺位于厦门市思明区五老峰下，是一座历史悠久的佛教寺院，也是闽南佛教文化的中心，始建于唐末五代（约907-960年），距今已有1000多年历史，因供奉观音菩萨，又在普陀山以南，故名“南普陀寺”。

南普陀寺占地面积约3万平方米，建筑面积约2万多平方米，主要建筑包括天王殿、大雄宝殿、大悲殿、藏经阁、钟鼓楼等，其中大雄宝殿是寺内的主殿，殿内供奉有释迦牟尼佛、迦叶尊者、阿难尊者三尊佛像，庄严肃穆。寺院后山有五老峰，登顶可俯瞰厦门大学和厦门港的美景。南普陀寺不仅是佛教圣地，也是免费赠送香火、提供素斋的慈善寺院，是了解闽南佛教文化、体验素食文化的绝佳去处。建议游览时间2-3小时。

### 3. 厦门大学（思明校区）

- **地址**：厦门市思明区思明南路422号
- **门票**：免费开放（需提前预约，工作日限300人/天，节假日限500人/天）
- **简介**：厦门大学位于厦门市思明区五老峰下，依山傍海，风景秀丽，是中国最美的大学之一，被誉为“山海花园大学”。厦门大学始建于1921年，由著名爱国华侨陈嘉庚先生创办，是中国近代教育史上第一所华侨创办的大学，距今已有100多年历史。

厦门大学思明校区占地面积约2.5平方公里，校园内建筑风格独特，融合了西洋风格和闽南特色，主要景点包括建南大礼堂、颂恩楼、芙蓉湖、情人谷、芙蓉隧道等，其中建南大礼堂是厦大的标志性建筑，建于1950年代，面朝大海，气势宏伟，是厦大最具代表性的景观之一。芙蓉隧道是厦大学生最爱的涂鸦隧道，全长1.1公里，隧道两侧墙壁上满是学生的涂鸦作品，创意十足，是厦大最具特色的文化景观之一。建议游览时间2-3小时。

### 4. 环岛路

- **地址**：厦门市思明区环岛路（全长约43公里）
- **门票**：免费开放
- **简介**：环岛路位于厦门市思明区东南沿海，全长约43公里，是厦门最著名的海滨景观大道，也是厦门国际马拉松赛的主赛道，素有“世界上最美的马拉松赛道”之美誉。环岛路依海而建，路宽景美，沿途设有多个观景台和休息区，是骑行、慢跑、散步的理想去处。

环岛路最著名的景观包括椰风寨、会展中心、黄厝海滩、椰风寨、音乐广场、海韵台等，其中椰风寨是环岛路上最热闹的地段之一，周边有大量的餐厅、咖啡馆、酒吧等，是体验厦门海滨夜生活的绝佳去处。环岛路还是厦门国际马拉松赛的主赛道，每年1月举行的厦门国际马拉松吸引了数万名跑者前来参赛，是厦门最具标志性的体育盛事之一。建议游览时间2-4小时（骑行或自驾）。

### 5. 曾厝垵

- **地址**：厦门市思明区环岛路曾厝垵片区
- **门票**：免费开放
- **简介**：曾厝垵位于厦门市思明区环岛路旁，是一个始建于明代的渔村，距今已有600多年历史，素有“中国最文艺渔村”之美誉。曾厝垵在2000年代开始转型，大量文艺青年在此开设民宿、咖啡馆、手工艺品店等，逐渐发展成为了厦门最具文艺气息的旅游街区。

曾厝垵占地面积约0.5平方公里，村内小巷交错，民宿、咖啡馆、手工艺品店、小吃店林立，是体验厦门文艺慢生活、品尝厦门特色小吃的绝佳去处。村内有大量的文创小店和特色民宿，每一家都有自己的故事和特色，是文艺青年最喜爱的打卡地之一。夜晚的曾厝垵格外迷人，小酒吧灯光闪烁，民谣声声入耳，是体验厦门夜生活的绝佳去处。建议傍晚时分前往，可以同时欣赏日景和夜景，游览时间2-3小时。

## 美食餐厅

### 1. 沙茶面（乌糖沙茶面）

- **地址**：厦门市思明区民族路54号
- **推荐菜品**：沙茶面、海蛎煎、土笋冻
- **人均消费**：30-50元
- **简介**：沙茶面是厦门最具代表性的特色小吃，用沙茶酱、花生酱、辣椒油等多种调料烹制汤头，搭配海鲜、猪杂、蔬菜等，味道鲜美独特，是厦门人最喜爱的早餐和夜宵之一。

### 2. 海蛎煎（莲欢海蛎煎）

- **地址**：厦门市思明区局口街局口横巷33号
- **推荐菜品**：海蛎煎、面线糊、土笋冻
- **人均消费**：20-40元
- **简介**：海蛎煎是厦门最具代表性的特色小吃，用海蛎、鸡蛋、番薯粉等煎制而成，外酥里嫩，鲜香味美，是到厦门必尝的特色美食。

### 3. 土笋冻（西门外土笋冻）

- **地址**：厦门市思明区西门外（多家小摊）
- **推荐菜品**：土笋冻、海蛎煎、烧肉粽
- **人均消费**：15-30元
- **简介**：土笋冻是厦门最具特色的平民小吃，用海沙虫（星虫）熬煮冷却后凝固而成，口感Q弹，味道鲜美，是厦门人最喜爱的夜宵之一。

### 4. 厦门烧肉粽（1980烧肉粽总店）

- **地址**：厦门市思明区中山路353号
- **推荐菜品**：烧肉粽、扁食汤、鱼丸汤
- **人均消费**：25-50元
- **简介**：烧肉粽是厦门最具代表性的特色小吃，用糯米包裹猪肉、香菇、栗子等馅料，外叶用竹叶包裹，蒸熟后香气四溢，是厦门人最喜爱的早餐之一。

### 5. 姜母鸭（厦门姜母鸭总店）

- **地址**：厦门市思明区大同路17号
- **推荐菜品**：姜母鸭、麻油鸡、猪脚姜
- **人均消费**：60-100元
- **简介**：姜母鸭是厦门最具代表性的滋补美食，用番鸭、老姜、麻油、米酒等炖煮而成，味道醇厚，滋补养身，是厦门人最喜爱的家常菜之一。

## 住宿推荐

### 1. 厦门海港英迪格酒店

- **地址**：厦门市思明区鹭江道16号
- **价格区间**：1000-2500元/晚
- **特色**：五星级精品酒店，位于鹭江道，紧邻鼓浪屿轮渡码头，部分客房可俯瞰鼓浪屿和厦门港美景，设计时尚，服务优质，是商务出行和高端旅游的理想选择。

### 2. 厦门喜来登酒店

- **地址**：厦门市思明区嘉禾路386-1号
- **价格区间**：800-1800元/晚
- **特色**：五星级商务酒店，位于嘉禾路核心地段，装修典雅豪华，设施一流，服务细致入微，是厦门市标志性豪华酒店之一。

### 3. 如家酒店（厦门中山路店）

- **地址**：厦门市思明区中山路步行街268号
- **价格区间**：200-400元/晚
- **特色**：经济型连锁酒店，位于中山路步行街核心地段，购物交通便利，房间干净整洁，性价比高，适合预算有限的游客。

### 4. 鼓浪屿民宿聚集区

- **地址**：厦门市思明区鼓浪屿岛上（多家民宿）

- **特色**：鼓浪屿上有大量的家庭式民宿，多为历史建筑改建而成，风格各异，充满文艺气息，是体验鼓浪屿慢生活的理想住宿选择。

### 5. 曾厝垵民宿聚集区

- **地址**：厦门市思明区曾厝垵片区内（多家民宿）
- **价格区间**：150-500元/晚
- **特色**：曾厝垵内有大量的文艺民宿，价格实惠，主人热情好客，提供家常菜和旅游咨询服务，是体验厦门文艺慢生活的经济之选。

## 交通信息

- **机场**：厦门高崎国际机场，位于厦门市湖里区翔云一路1号，距市中心约12公里，已开通国内外多条航线。
- **火车站**：厦门站（思明区厦禾路），厦门北站（集美区岩顺路），厦门东站（在建）。
- **地铁**：厦门地铁目前有3条线路运营，覆盖主要城区和景点。
- **公交**：公交线路发达，票价1-2元，部分旅游专线可直达鼓浪屿轮渡码头、厦门大学、南普陀寺等主要景点。
- **出租车/网约车**：起步价10元（3公里），超过3公里后每公里2.4元。
- **轮渡**：从厦门轮渡码头（思明区鹭江道）乘船可到达鼓浪屿，是游览鼓浪屿的主要交通方式。

## 旅游小贴士

1. **最佳旅游时间**：春季（3-5月）和秋季（9-11月）气候宜人，是游览厦门的最佳时节。
2. **游览建议**：建议安排3-4天时间游览厦门，可将鼓浪屿、南普陀寺、厦门大学、环岛路、曾厝垵等景点串联游览。
3. **特色体验**：乘坐渡轮欣赏鹭江两岸风光，参观厦门大学感受最美大学校园，骑行环岛路欣赏海滨美景，品尝地道的厦门口味。
4. **购物推荐**：中山路步行街、思明北路是厦门最繁华的购物区，可以购买到各类商品和厦门特产（如馅饼、海蛎干、鱼皮花生等）。
5. **注意事项**：鼓浪屿轮渡需提前预约购票，尤其是节假日期间；参观厦门大学需提前预约，且限流；夏季厦门炎热多雨，需做好防暑降温和防雨准备。
