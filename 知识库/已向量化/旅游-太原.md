# 太原旅游信息文档

## 城市概况

太原，别称并州、晋阳、龙城，是山西省省会，位于山西省中部，太原盆地北端，东、西、北三面环山，中南部为河谷平原，汾河自北向南穿城而过。全市总面积6988平方公里，常住人口约530万，下辖6区3县1市。太原是一座有着2500多年建城史的国家历史文化名城，是中华文明的重要发祥地之一，自古就有"锦绣太原城"的美誉。

太原最著名的旅游名片当属晋祠、山西博物院、天龙山石窟、蒙山大佛等。晋祠是中国现存最早的皇家祭祀园林，始建于西周时期，是为纪念晋国开国诸侯唐叔虞而建，集中国古代祭祀建筑、园林、雕塑、壁画、碑刻艺术为一体，被誉为"中国建筑博物馆"。山西博物院是国家一级博物馆，馆藏文物多达40余万件，其中包括鸟尊、侯马盟书、木板漆画等珍贵文物，是了解山西历史文化的重要窗口。太原属暖温带大陆性季风气候，四季分明，夏季凉爽，是理想的避暑胜地，最佳旅游时间为5-10月。

## 旅游景点

### 1. 晋祠景区

- **地址**：太原市晋源区晋祠镇晋祠路2号
- **门票**：80元/人（成人），40元/人（学生/老人）
- **简介**：晋祠位于太原市西南25公里的悬瓮山麓，晋水源头，是中国现存最早的皇家祭祀园林，也是全国重点文物保护单位，国家AAAA级旅游景区。晋祠始建于西周时期（公元前11世纪），是为纪念晋国开国诸侯唐叔虞而建，历经各代修葺扩建，形成了集祭祀建筑、园林、雕塑、壁画、碑刻艺术为一体的珍贵历史文化遗产。

晋祠最著名的景观是"晋祠三绝"：一是圣母殿，始建于北宋天圣年间（1023-1032年），是中国现存古建筑中最早的带围廊的宫殿式建筑，殿内供奉有圣母邑姜（唐叔虞之母）及42尊侍女像，塑像栩栩如生，神态各异，是中国古代雕塑艺术的瑰宝；二是鱼沼飞梁，位于圣母殿前，是一座十字形桥梁，建于北宋，是中国现存古桥中唯一的孤例；三是难老泉，是晋水的主要源头，泉水清澈见底，长流不息，北齐时被赞誉为"难老"。此外，晋祠还有水镜台、献殿、钟鼓楼、金人台等众多历史文化遗迹，是了解中国古代建筑、雕塑、壁画艺术的绝佳去处。建议游览时间3-4小时。

### 2. 山西博物院

- **地址**：太原市滨河西路北段13号
- **门票**：免费开放（需提前预约）
- **简介**：山西博物院位于太原市汾河西岸，是山西省最大的文物收藏、保护、研究和展示中心，国家一级博物馆。博物院占地面积约7.3万平方米，建筑面积约5.2万平方米，收藏有各类文物40余万件，其中珍贵文物约4万余件，包括一级文物约2000件。

山西博物院的馆藏文物上起远古，下至近现代，涵盖了山西地区各个历史时期的文化遗存，其中以青铜器、陶瓷器、书画、石刻等最具特色。镇馆之宝包括西周鸟尊、春秋侯马盟书、北齐木板漆画、北魏司马金龙墓出土文物等，每一件都是国之瑰宝。博物院主馆建筑造型独特，形似"斗"和"鼎"的组合，寓意"鼎盛三晋"，是太原市的标志性文化建筑之一。博物院常年设有"晋魂"基本陈列，分为文明摇篮、夏商踪迹、晋国霸业、民族熔炉、佛风遗韵、戏曲故乡、明清晋商等七个专题，系统展示了山西地区的历史文化发展脉络。建议游览时间3-4小时，是了解山西历史文化的绝佳去处。

### 3. 天龙山石窟

- **地址**：太原市晋源区天龙山景区
- **门票**：50元/人（成人），25元/人（学生/老人）
- **简介**：天龙山石窟位于太原市西南40公里的天龙山，是南北朝至隋唐时期重要的佛教石窟艺术遗址，始凿于东魏武定二年（544年），后历经北齐、隋、唐各代连续开凿，形成了25个洞窟、500余尊造像的规模。天龙山石窟以精美的佛像造型和细腻的雕刻技艺而著称，被誉为"东方雕塑艺术的宝库"。

天龙山石窟的造像艺术在中国佛教石窟艺术发展史上具有重要地位，尤其是唐代造像，面相丰满圆润，体态丰腴健美，衣纹流畅自然，充分体现了盛唐时期的精神风貌和艺术水平。第8窟的唐代佛像和第16窟的北齐佛像是最具代表性的作品。然而，天龙山石窟的造像在20世纪初遭到了严重盗掘，大量佛首流失海外，成为中国文化遗产的重大损失。2021年，在习近平总书记的关心推动下，天龙山佛首回归故里，入藏天龙山石窟博物馆，成为文物回归的典范。如今的天龙山石窟已修建了完善的游览设施，游客可以在此欣赏到精美的石窟艺术，感受古代工匠的智慧和技艺。

### 4. 蒙山大佛

- **地址**：太原市晋源区罗城街道蒙山大佛景区
- **门票**：50元/人（成人），25元/人（学生/老人）
- **简介**：蒙山大佛位于太原市西南约20公里的蒙山，是一尊北齐时期开凿的摩崖大佛，距今已有约1500年历史。蒙山大佛开凿于北齐天保年间（550-559年），佛身高约63米，比著名的乐山大佛（71米）略低，但开凿时间比乐山大佛早162年，是中国现存最早的大型摩崖造像之一。

蒙山大佛在元朝时期被毁，佛首和手臂部分损毁严重，仅存巨大的佛身，在沉睡了数百年后，于1980年代被重新发现。2007年，太原市启动了蒙山大佛修复工程，对佛身进行了加固和修复，并新铸了佛首。修复后的蒙山大佛气势恢宏，庄严肃穆，吸引大量游客和信众前来参观朝拜。除了大佛，蒙山景区还有开化寺、铁佛殿、连理塔等历史文化遗迹，以及优美的自然风光，是集历史文化与自然景观于一体的综合性旅游景区。建议游览时间2-3小时。

### 5. 太原古县城

- **地址**：太原市晋源区太原古县城景区
- **门票**：免费开放（部分景点收费）
- **简介**：太原古县城位于太原市晋源区，是在明代太原县城（晋源古城）的基础上修复重建的，占地面积约0.8平方公里，总建筑面积约36万平方米。古县城城垣方整，街道规整，保留了明代县城的基本格局，被誉为"凤凰城"。

太原古县城内设有县衙、文庙、关帝庙、城隍庙、魁星楼等多处历史文化景点，还有各式各样的山西特色小吃和手工艺品店，是体验山西民俗文化、品尝山西美食的绝佳去处。城内的县衙是按照明代县衙的规制重建的，游客可以在此了解明代的司法制度和官场文化；文庙是祭祀孔子的场所，建筑雄伟，文化底蕴深厚。此外，太原古县城还是电影《满江红》的拍摄地，吸引了大量影迷前来打卡。夜晚的古县城灯火辉煌，别有一番韵味，建议傍晚时分前往，可以同时欣赏日景和夜景。

## 美食餐厅

### 1. 山西刀削面（太原老字号）

- **地址**：太原市迎泽区柳巷北路56号
- **推荐菜品**：刀削面、剔尖、拨烂子
- **人均消费**：20-40元
- **简介**：刀削面是山西最具代表性的面食，始于元代，以刀功闻名——厨师一手托面团，一手持特制弯刀，削出的面片形似柳叶，中厚边薄，入口筋道滑爽。太原老字号刀削面馆是太原最有名的面食店，已有50多年历史，是品尝正宗山西面食的绝佳去处。

### 2. 太原头脑

- **地址**：太原市迎泽区桥头街28号
- **推荐菜品**：头脑（八珍汤）、帽盒子
- **人均消费**：15-30元
- **简介**：头脑是太原特有的传统名吃，又名"八珍汤"，由黄芪、良姜、羊肉、山药、藕根、面精、酒糟等八种原料配制而成，味道独特，营养丰富，是太原人最喜爱的早餐之一。

### 3. 山西老陈醋（宁化府）

- **地址**：太原市迎泽区桥头街宁化府巷18号（特产店）
- **推荐菜品**：老陈醋、醋饮料、醋保健品
- **人均消费**：30-100元（购买伴手礼）
- **简介**：山西老陈醋是中国四大名醋之一，距今已有3000余年的历史，素有"天下第一醋"之美誉。宁化府是太原最著名的老陈醋品牌，醋香浓郁，酸味醇厚，久放不腐，是太原最具代表性的伴手礼之一。

### 4. 过油肉

- **地址**：太原市迎泽区食品街32号
- **推荐菜品**：过油肉、糖醋丸子、山西烧肉
- **人均消费**：40-80元
- **简介**：过油肉是山西最著名的传统菜肴，被誉为"三晋一味"，始于明代，已有数百年的历史。选料讲究，制作精细，色泽金黄，味道咸鲜，外软里嫩，是山西菜系的代表之作，也是到太原必尝的特色美食。

### 5. 太原羊杂割

- **地址**：太原市杏花岭区解放路102号
- **推荐菜品**：羊杂割、羊汤、烧饼
- **人均消费**：25-50元
- **简介**：羊杂割是太原的传统小吃，用羊肚、羊肝、羊肺、羊肠等羊杂碎，配以粉条、香菜、辣椒等烹制而成，汤色乳白，味道鲜美，辣香扑鼻，是太原人最喜爱的早餐和夜宵之一。

## 住宿推荐

### 1. 太原凯宾斯基饭店

- **地址**：太原市小店区长风商务区谐园路6号
- **价格区间**：800-1800元/晚
- **特色**：五星级豪华酒店，位于长风商务区，紧邻汾河公园，装修典雅豪华，设施一流，服务优质，是商务出行和高端旅游的理想选择。

### 2. 太原星河湾酒店

- **地址**：太原市小店区星河中路2号
- **价格区间**：600-1500元/晚
- **特色**：五星级商务酒店，位于星河湾小区内，环境优美，设施豪华，客房宽敞舒适，服务细致入微，是太原市标志性豪华酒店之一。

### 3. 如家酒店（太原柳巷店）

- **地址**：太原市迎泽区柳巷南路78号
- **价格区间**：150-280元/晚
- **特色**：经济型连锁酒店，位于柳巷商业街核心地段，购物交通便利，房间干净整洁，性价比高，适合预算有限的游客。

### 4. 太原古县城民宿

- **地址**：太原市晋源区太原古县城内
- **价格区间**：200-400元/晚
- **特色**：古色古香的主题民宿，位于太原古县城内，建筑风格古朴典雅，充满明清韵味，是体验古城文化、感受山西民俗的理想住宿选择。

### 5. 太原晋祠宾馆

- **地址**：太原市晋源区晋祠路2号（晋祠对面）
- **价格区间**：400-800元/晚
- **特色**：四星级园林式酒店，位于晋祠对面，环境清幽，空气清新，客房分布在花园般的环境中，是游览晋祠后理想的休息之处。

## 交通信息

- **机场**：太原武宿国际机场，位于太原市小店区太榆路1号，距市中心约15公里，已开通国内外多条航线。
- **火车站**：太原站（迎泽区建设南路），太原南站（小店区太榆路），太原东站（杏花岭区）。
- **地铁**：太原地铁目前有2条线路运营，覆盖主要城区和景点。
- **公交**：公交线路发达，票价1-2元，部分旅游专线可直达主要景点。

## 旅游小贴士

1. **最佳旅游时间**：春季（5-6月）和秋季（9-10月）气候宜人，是游览太原的最佳时节。
2. **游览建议**：建议安排2-3天时间游览太原，可将晋祠、山西博物院、天龙山石窟、蒙山大佛等景点串联游览。
3. **特色体验**：品尝地道的山西面食，参观博物院了解山西历史文化，逛太原古县城体验明清民俗。
4. **购物推荐**：柳巷商业街、服装城是太原最繁华的购物区，可以购买到各类商品和山西特产。
5. **注意事项**：太原气候干燥，需注意多喝水；参观寺庙时注意着装得体，保持安静。
